# Lubao (路宝) — биржа грузов Хоргос

## Суть
Приложение сводит водителей грузовиков, ожидающих груз на Хоргосе,
с логистическими компаниями (в основном на китайской стороне).
Главная цель: водитель и логист находят друг друга быстро и просто.

## Стек
- apps/lubao_app — Flutter (iOS, Android, Web). Роли: водитель, логист.
- apps/lubao_admin — Flutter Web, админка.
- packages/lubao_core — общие модели, API-клиент, l10n, тема, UI-кит.
- backend — NestJS + Prisma + PostgreSQL + Redis, WebSocket (Socket.IO).
- infra — Docker Compose: postgres, redis, minio, nginx.
- Flutter: Riverpod, go_router, Dio, flutter_localizations (ARB).

## Языки
- kk (кириллица), ru, zh (упрощённый). Автоопределение по языку
  устройства, fallback — ru, ручное переключение в профиле.
- НИКАКИХ захардкоженных строк в UI — только ARB.
- Справочники в БД хранят названия как JSON {kk, ru, zh}.
- Архитектура должна позволять добавить kk-Latn позже.

## Ключевые ограничения
- Персональные данные хранятся на серверах в РК.
- Логисты в Китае: на их стороне не зависеть от Google
  (FCM, Maps, Sign-In). Push: FCM (KZ) + APNs + JPush (Android CN).
  Уведомления компаниям — также через WeCom group bot webhook.
- Вход: водитель — телефон + SMS (+7); компания — email + пароль.
- Модуль уведомлений — абстракция каналов: push, wecom, email, sms
  (позже wechat, whatsapp).

## Доменная модель
users, drivers, vehicles, driver_directions, companies,
company_members (owner/logist), arrivals, cargos, responses,
deals, contact_events, chats, messages (оригинал + переводы),
reviews, справочники (points, countries, regions, cities,
body_types, permits, message_templates), verification_documents,
notification_settings, complaints, exchange_rates, audit_log,
subscriptions/payments (биллинг выключен флагом).

## Бизнес-правила
- Точка загрузки — справочник, на старте только Хоргос.
- Водитель выбирает страны (или «любое»), домашний город, допуски.
  Лента грузов: домой → выбранные страны → остальные.
- Цена груза обязательна, валюта USD/CNY/KZT, показ пересчёта
  по курсу НБ РК.
- Телефон и чат доступны сразу. Каждое нажатие «Позвонить»/WhatsApp
  пишется в contact_events; через 2 часа push «Договорились?».
- Сделка: отклик → выбран → подтверждён водителем → загружен →
  в пути → доставлено → отзывы. Отмена — только с причиной.
- Рейтинг и «Проверенный» — только по сделкам в приложении.
- Груз можно публиковать без водителей; архив через 3 дня
  после даты готовности. Анонс истекает через 48 ч после даты.
- Монетизация (подписка компании 200$/мес, 50$ с водителя
  за сделку) заложена, но выключена.

## Правила кода

- Тесты на бизнес-логику сделок и матчинга.
