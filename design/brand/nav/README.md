# Иконки нижнего меню (эталон 33)

Свои объёмные цветные иконки (градиенты, блик, мягкая тень — в духе эмодзи, которые понравились в эталоне 32) вместо линейных Lucide — одинаково выглядят на iOS, Android и в вебе (эмодзи в эталоне 32 рисуются по-разному на разных телефонах, поэтому не используем).

| Файл | Где |
|---|---|
| `cargo.svg` | Водитель — Грузы (фура, кабина слева) |
| `trips.svg` | Водитель — Мои рейсы (компас) |
| `boxes.svg` | Логист — Грузы (коробка) |
| `drivers.svg` | Логист — Водители (двое) |
| `chats.svg` | Чаты (обе роли) |
| `profile.svg` | Профиль (обе роли) |

Состояния: **активная** — цветная, как в файле, под иконкой подложка `#E6EBFF`, подпись синяя жирная; **неактивная** — та же цветная иконка, прозрачность 0,8, подпись серая (как в эталоне 32 — цветные все, выбранная на подложке). Размер 28–32 dp. Бейдж-цифра — красный кружок справа сверху.

В Flutter — `flutter_svg` (`SvgPicture.asset`), файлы скопировать в `lubao_core/assets/nav/`; градиенты в SVG `flutter_svg` поддерживает. Проверить, что тень-эллипс не обрезается в 48×48.
