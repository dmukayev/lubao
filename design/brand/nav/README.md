# Иконки нижнего меню (эталон 33)

Свои цветные иконки вместо линейных Lucide — одинаково выглядят на iOS, Android и в вебе (эмодзи в эталоне 32 рисуются по-разному на разных телефонах, поэтому не используем).

| Файл | Где |
|---|---|
| `cargo.svg` | Водитель — Грузы |
| `trips.svg` | Водитель — Мои рейсы |
| `boxes.svg` | Логист — Грузы |
| `drivers.svg` | Логист — Водители |
| `chats.svg` | Чаты (обе роли) |
| `profile.svg` | Профиль (обе роли) |

Состояния: **активная** — цветная, как в файле, под иконкой подложка `#E6EBFF`, подпись синяя жирная; **неактивная** — та же иконка в оттенках серого (ColorFiltered / saturation 0, прозрачность 0,55), подпись серая. Размер 28–32 dp. Бейдж-цифра — красный кружок справа сверху.
