# Миниатюры типов кузова

SVG 160×80, вид сбоку, кабина слева. Два цвета: кузов — `primary` `#1F4FFF`, рама/кабина/колёса — `#0E1526`; в тёмной теме и в выбранном состоянии перекрашиваются через `currentColor`/замену цветов. Имя файла = `code` справочника `body_types` в нижнем регистре; `tractor.svg` — тягач без прицепа (Vehicle.kind TRACTOR), `rigid.svg` — одиночка (kind RIGID). Эталон экрана — `design/screens/29-vehicle-type-icons.png`.
Использовать: регистрация водителя (шаг «Какая у вас машина?»), гараж (карточка машины), «Кто свободен» и отклик у логиста (мелко, 40 px), карточка груза («нужен кузов»). Новому типу кузова в админке — новый файл по тому же стилю.
