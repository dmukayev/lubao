# Пул идей (не задачи)

Идеи собираются здесь, пока владелец не решит делать. Задачи из них пишет архитектурный чат. Claude Code отсюда ничего не берёт.

## Рост: откуда взять людей (2026-10-11)
- **Telegram-канал «Грузы Хоргос — Lubao».** Каждый новый груз автоматически публикуется в канал (бот только пишет, входа через бот нет).
- **Пригласить своих водителей из контактов.** Телефонная книга с галочками → разом приглашения в «Мои водители».
  - Отправка с номера логиста:
    - WhatsApp по очереди (wa.me с готовым текстом);
    - в группу или рассылку;
    - SMS на Android со всеми номерами.
  - На ПК — вставить список номеров. Правила те же, что у «Создать водителя».
- **Страница скачивания APK** (lubao.kz/app) — для водителей без Play Store.
- **Оффлайн (Болат):**
  - 10–20 логистов вручную;
  - «опубликуем за вас» — оператор заносит грузы из WhatsApp от имени компании с её согласия;
  - стоянки и очереди у Хоргоса и Алтынколя с QR-листовками;
  - бонус 1 000 ₸ за пройденную проверку.
- **Партнёры:**
  - таможенные брокеры и СВХ;
  - сухой порт «Хоргос — Восточные ворота»;
  - КазАТО;
  - заправки и шиномонтажи (QR-плакаты).
- **Китайская сторона** — WeChat-группы экспедиторов и китаеговорящий агент (после пилота).

## Удержание: зачем открывать каждый день (2026-10-11)
1. **Груз из сообщения.** Логист пересылает или вставляет текст вида «Хоргос — Астана, 20 т, тент, 850 тыс, завтра» → разбор в карточку (DeepSeek) → проверить → «Опубликовать». ⭐ в первую очередь.
2. **Уведомления по своему направлению.** Сохранённый фильтр ленты → push о каждом новом подходящем грузе. ⭐ в первую очередь.
3. **Обратный груз.** Водитель «в пути» → за полдня до прибытия: «В Астане 6 грузов в вашу сторону».
4. **Очередь на границе.** Водители отмечают очередь на Хоргосе и Алтынколе («~300 машин, 14:20»).
5. **Утренняя сводка логисту** (push / WeCom): «Сейчас на Хоргосе 45 свободных машин: тент 30, реф 8».
6. **Узбекский язык** (латиница).

## Ещё (2026-10-12)
- **Голосовые сообщения в чате с расшифровкой и переводом.** Водители больше говорят, чем пишут; логист из Китая получает текст на китайском.
- **Фото документов рейса в сделке.** Фото CMR / накладной при погрузке и подписанной накладной при выгрузке. Логисту — доказательство доставки, водителю — быстрее остаток оплаты.
- **Где сейчас машина.** Водитель по желанию делится местоположением на время «в пути»; логист видит точку на карте и примерное время прибытия. Отключается после «доставлено».
- **«Передать груз другу».** Водитель не может взять груз → «Порекомендовать водителя» из своих контактов; логисту приходит рекомендация. Водители верят друг другу.
- **Значки надёжности:**
  - «20 рейсов без отмен»;
  - «Отвечает за 5 минут»;
  - «На платформе год».
  Только по фактам в приложении.
- **Цены по маршруту для логиста** — график цен за месяц по направлению и кузову из статистики 047. Позже — платная функция для компаний.
- **Скидки партнёров для проверенных водителей** — топливные карты, страховка, шиномонтаж. Причина пройти проверку и оставаться.
- **Агентская программа** — полевые агенты (как Болат) получают фиксированную плату за каждого водителя, прошедшего проверку и сделавшего первый рейс; учёт по ссылкам «Поделиться» в админке.
- **Работа при слабом интернете на трассе.** Лента и «Мои рейсы» открываются из кэша; отклик или статус ставится в очередь и отправляется, когда появится сеть.
