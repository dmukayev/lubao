# Админка с телефона (задача 030)

Админ одобряет документы, разбирает жалобы и блокирует нарушителей
чаще всего с телефона — проверять мобильную раскладку нужно на
настоящем устройстве, не только эмулятором на том же Mac.

## Сейчас (разработка, всё на Mac)

1. Backend и Postgres/Redis/MinIO уже слушают на всех интерфейсах через
   `infra/docker-compose.yml` (`ports: "3000:3000"` и т.д.) — отдельно
   настраивать не нужно.

2. Поднять админку как веб-сервер, слушающий не только localhost:

   ```bash
   cd apps/lubao_admin
   flutter run -d web-server --web-hostname 0.0.0.0 --web-port 5566 \
     --dart-define=API_BASE_URL=http://<имя-или-IP-мака>:3000
   ```

   `API_BASE_URL` — обязательно: без него Flutter Web обращается к
   `localhost:3000`, а на телефоне `localhost` — это сам телефон, не Mac
   (см. `apps/lubao_admin/lib/providers/api_providers.dart`).

3. Если бэкенд должен принимать запросы только с конкретных origin (не
   обязательно на пилоте, но доступно) — задать в `backend/.env`:

   ```
   CORS_ALLOWED_ORIGINS=http://<имя-мака>.tailnet-name.ts.net:5566,http://192.168.1.50:5566
   ```

   Не задано — CORS открыт для всех (сегодняшнее поведение, ок для
   обычной локальной разработки).

## Вариант А — Tailscale (рекомендуется)

1. Установить Tailscale на Mac и на телефоне, зайти в один и тот же
   tailnet.
2. Узнать имя машины в tailnet: `tailscale status` на Mac (или в панели
   Tailscale) — что-то вроде `my-mac.tailnet-name.ts.net`.
3. На телефоне открыть `http://<имя-мака>.tailnet-name.ts.net:5566`.

Почему Tailscale, а не просто LAN: работает и не в одной Wi-Fi сети
(например, телефон на мобильном интернете), трафик зашифрован без
дополнительной настройки HTTPS для теста.

## Вариант Б — одна Wi-Fi сеть

1. Узнать локальный IP Mac: `ipconfig getifaddr en0` (или через Системные
   настройки → Wi-Fi → Подробности).
2. На телефоне (в той же сети) открыть `http://192.168.x.x:5566`.
3. Указать тот же адрес в `API_BASE_URL` при запуске (`--dart-define
   =API_BASE_URL=http://192.168.x.x:3000`) и, если включали, в
   `CORS_ALLOWED_ORIGINS`.

## На проде

Админка **не выставляется в открытый интернет** — доступ только через
частную сеть (Tailscale) или с ограничением по IP, через HTTPS (см.
`docs/decisions.md` → «Админка на телефоне», 2026-10-05). Через админку
видны документы и переписка всех пользователей — обычная защита
логином недостаточна. Если позже понадобится открытый адрес — только
со вторым фактором входа (TOTP); пока не реализовано.

## Чек-лист ручной проверки (раз в релиз, с настоящего iPhone)

- Одобрить документ водителя — зум двумя пальцами открывается, кнопки
  «Подтвердить»/«На доработку» видны без скролла.
- Разобрать и закрыть жалобу.
- Заблокировать и разблокировать тестового водителя.
- Открыть каждый из 5 пунктов нижней навигации (Сводка/Проверка/
  Жалобы/Поиск/Ещё) — ничего не обрезается по ширине.
