# Ручная проверка функционала (smoke-test)

Версия: 2026-10-04 (обновлено после 006/021/022), по коду до задач 006–024. Цель — пройти основные сценарии водителя, логиста и админа и записать, что работает, а что нет.

Как отмечать: у каждого шага поставьте ✅ (работает как ожидается) или ❌ + что произошло (скриншот). Пункты из раздела «Известные ограничения» отмечать не нужно — они уже в задачах.

## 0. Запуск
```
pnpm docker:up
pnpm prisma:migrate
pnpm prisma:seed
pnpm --filter backend prisma:seed:demo
pnpm dev:backend
```
Второй терминал: `cd apps/lubao_app && flutter run` (Chrome или Android-эмулятор).
Третий (для админки): `cd apps/lubao_admin && flutter run -d chrome --web-port 5566`.

Демо-доступы — `DEMO_CREDENTIALS.md`. Код из SMS в разработке — **1111**,
код из email (логист) — **111111**.

> Эмулятор: печатайте экранной клавиатурой эмулятора (добавьте русскую раскладку в Gboard), клавиатура компьютера передаёт только латиницу.

## Известные ограничения (уже в задачах — не отмечать)
- Нет анонса «буду завтра» — только «я на месте сейчас», терминал не выбирается → **015**
- Нет автоподстановки кода из SMS/email (Android SMS Retriever, iOS one-time-code) — код вводится вручную → **021**
- Регистрация компании — только путь «Создать» (владелец); приглашение сотрудника по ссылке и создание компании админом ждут таблицы `company_invites` из задачи **012** → **022**
- Доработки авторизации после ревью 006: офлайн-разлогин, гонка попыток кода, устаревший lock-файл, гонка при параллельном refresh в двух вкладках → **024**
- Чат только внутри сделки, нет закрытия груза с исходом → **017**
- Подтверждение сделки без верификации не блокируется сервером → **007**
- В текстах «Хоргос», часть строк не переведена → **007**
- Лента грузов не скрывает грузы без нужных допусков → **016**
- Нет push-уведомлений, автоперевода чата, геолокации по правилам → **011, 010, 008**
- Курс валют не обновляется, анонсы и грузы не истекают → **018**
- Профили не по макетам 07/08 → **009, 012**
