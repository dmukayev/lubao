# 025 — Вход и регистрация логиста по телефону и паролю

Статус: не начато · **решение владельца продукта 2026-10-04** (заменяет вход по коду на email из 006/022)

Эталоны: `design/screens/13-auth-logist-login.png` (вход), `12-register-logist.png` (регистрация компании). Решение — `docs/decisions.md` (2026-10-04, «Логист: телефон + пароль»).

## Что сделать

### Вход (экран 13)
1. Телефон с выбором кода страны (по умолчанию **+86**, рядом +7 и список) + пароль → «Войти». Кнопки «Зарегистрировать компанию», «У меня приглашение от компании», «Забыли пароль?».
2. `POST /auth/company/login {phone, password}` → пара токенов (сессии из 006, срок 30 дней). Пароль — bcrypt.
3. Защита: 5 неверных паролей на номер → блокировка входа на 15 минут; лимит 20 попыток в час с одного IP; одинаковый текст ошибки «Неверный телефон или пароль» (не раскрывать, существует ли номер).

### Регистрация компании (экран 12) — один экран
4. Поля: телефон, пароль (≥ 8 символов, показать/скрыть), имя, название компании (+ русское, подставляется — можно поправить), страна (Китай / Казахстан / Другая). Город не спрашиваем.
5. `POST /auth/company/register` → создаёт `User{role: COMPANY, phone, passwordHash, name}` + `Company` + `CompanyMember{OWNER}` в одной транзакции (переиспользовать `registerOwnedCompany` из 022) → токены → кабинет с баннером «Публикация грузов откроется после проверки».
6. Номер уже зарегистрирован → «Этот номер уже зарегистрирован. Войти?» (с переходом на вход, номер подставлен).
7. **Подтверждение номера:**
   - **+7 (Казахстан)** — SMS-код при регистрации (существующий `SmsService`, лимиты как у водителя);
   - **другие страны (+86 и т. д.)** — SMS не отправляем (рассылка на китайские номера требует отдельной регистрации шаблонов и дорогая); номер подтверждает админ при проверке компании (звонок на официальный номер из реестра и на номер логиста — добавить пункт «номер логиста подтверждён» в чек-лист проверки, задача 012). Пока компания не проверена, публиковать грузы и так нельзя.
   - Поле `User.phoneVerifiedAt`.

### Восстановление пароля
8. «Забыли пароль?»:
   - номер **+7** — SMS-код → новый пароль;
   - другой номер — если в профиле указан email (необязательное поле «Email для восстановления» в «Мой профиль») — код на email (`EmailService` из 006) → новый пароль; если email нет — экран «Напишите в поддержку» (WhatsApp / WeChat / email поддержки — контакты из `app_settings`), админ сбрасывает пароль вручную в админке (кнопка «Сбросить пароль» → временный пароль, обязательная смена при входе).
   - После смены пароля — все остальные сессии завершаются.

### Приглашение сотрудника (Путь Б из 022)
9. Владелец в «Сотрудники» → «Пригласить» → вводит **телефон** и роль → получает **ссылку-приглашение**, которую сам отправляет коллеге в WeChat/WhatsApp (кнопки «Скопировать», «Поделиться»). Email-рассылка не нужна.
10. По ссылке: телефон подставлен → пароль, имя, телефон для водителей (по умолчанию тот же), WeChat → готово, сразу в кабинете компании. Ссылка действует 7 дней, одноразовая.

### Что убрать / оставить
11. Экран входа логиста по коду на email (`company_login_screen` / `company_otp_screen`) — убрать из навигации. `EmailService` оставить — используется для восстановления пароля (п. 8).
12. Демо-аккаунты компаний в `seed-demo.ts` и `DEMO_CREDENTIALS.md` — перевести на телефон + пароль.
13. Миграция: у существующих COMPANY-пользователей без телефона — при следующем входе по старому email-коду (временно, до конца пилота) попросить указать телефон и пароль. Или проще для пилота: пересоздать демо-данные.
14. Все строки — ARB (kk/ru/zh/en).

## Готово, когда
- Логист входит по телефону и паролю; 6-й неверный пароль → блокировка 15 минут.
- Новая компания регистрируется на одном экране; казахстанский номер подтверждается SMS, китайский — без SMS.
- «Забыли пароль» работает для +7 (SMS) и для номера с email (код на почту); без email — понятный экран поддержки и сброс пароля админом.
- Сотрудник регистрируется по ссылке-приглашению и попадает в нужную компанию.
- Тесты: вход, блокировка, регистрация, дубль номера, сброс пароля, приглашение.
