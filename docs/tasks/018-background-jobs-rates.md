# 018 — Фоновые задачи и курс валют НБ РК

Статус: не начато · после 006 (нужен до 014, 015, 017)

## Проблема (ревью 2026-10-04)
В бэкенде нет ни одной фоновой задачи (`@Cron`, очередей). Курсы валют только читаются из `exchange_rates`, но никто их не загружает. Не работают: истечение анонсов, архив грузов, вопросы «Договорились?», «Вы ещё на Хоргосе?».

## Что сделать
1. Планировщик: `@nestjs/schedule` для расписаний + BullMQ (Redis) для отложенных задач (например, «через 2 часа после звонка»). Задачи идемпотентны; при нескольких экземплярах бэкенда — блокировка в Redis, чтобы задача выполнялась один раз.
2. **Курс валют НБ РК** — ежедневно в 10:00 по Алматы (и при старте, если на сегодня курса нет): официальный курс USD и CNY к KZT с сайта Национального банка РК (`nationalbank.kz`, RSS/XML официальных курсов). Сохранять в `exchange_rates` (source `nbrk`). При ошибке — повтор каждый час, в API отдавать последний доступный курс + дату.
3. Регулярные задачи:
   | Задача | Расписание | Действие |
   |---|---|---|
   | Архив грузов | каждый час | `PUBLISHED`, у которых `readyDate` + 3 дня прошло → `ARCHIVED` |
   | Истечение анонсов | каждые 15 мин | по `expiresAt` / `plannedAt` (задачи 014, 015) |
   | «Вы ещё на Хоргосе?» | каждые 15 мин | выбрать анонсы для вопроса (014) |
   | Очистка треков | раз в сутки | точки трека старше 30 дней после сделки (008) |
4. Отложенные: «Договорились?» через 2 часа после звонка (017).
5. Админка: страница «Фоновые задачи» — последний запуск, результат, ошибки; кнопка «Запустить сейчас».

## Готово, когда
- В `exchange_rates` каждый день появляются курсы USD и CNY от НБ РК; лента показывает пересчёт по сегодняшнему курсу.
- Груз с датой готовности 4 дня назад сам уходит в архив.
- При двух запущенных экземплярах бэкенда задача выполняется один раз (тест).
