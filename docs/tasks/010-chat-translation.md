## Текущее состояние
`Message` уже хранит `originalText`, `originalLang`, `translations` (Json), но сервиса перевода нет — `translations` не заполняется. Чат — запросами, не в реальном времени (real-time — задача 011).

## Что сделать
### Бэкенд — модуль `translation`
0. Языки: kk, ru, zh, en (решение 2026-10-04).
1. Интерфейс `TranslationProvider.translate(text, from, to[], context) → {lang: text}`. Реализация **`DeepSeekTranslationProvider`**: API DeepSeek совместим с OpenAI (`https://api.deepseek.com`, chat completions) — использовать официальный OpenAI SDK для Node с `baseURL`. В `.env`: `TRANSLATION_PROVIDER=deepseek`, `DEEPSEEK_API_KEY`, `DEEPSEEK_MODEL` (имя модели **не хардкодить** — у DeepSeek модели переименовываются; взять текущую быструю/дешёвую из https://api-docs.deepseek.com на момент работы), `temperature` низкая (0–0.3). Второй провайдер-заглушка `Noop` (возвращает пусто → в чате показывается оригинал) — для dev без ключа и как аварийное отключение. Интерфейс оставляет возможность позже запустить открытую модель DeepSeek на своём сервере в РК (тот же OpenAI-совместимый формат — меняется только `baseURL`).
1а. Системный промпт + словарь — **неизменный префикс** в начале каждого запроса (у DeepSeek кэш префикса — повторный промпт стоит в разы дешевле); переменная часть (текст, языки) — в конце.
2. **Словарь терминов** `backend/src/translation/glossary.json`: термин на 4 языка kk/ru/zh/en (растаможка, тентовка/тент, реф, TIR-книжка, CMR, СВХ, пломба, перегруз, простой, предоплата, наличка/безнал, госномер, прицеп, тягач, МЦПС, Нур Жолы и т. п. — минимум 40 терминов). Подставляется в промпт.
3. Промпт: «Переведи сообщение из чата водителя и логиста. Сохраняй метки вида ⟦1⟧ без изменений. Не добавляй ничего от себя. Верни JSON {"<lang>": "<перевод>"}» (`response_format: json_object`). Без истории переписки — только текущее сообщение.
3а. **Метки для цифр** (решение 2026-10-05, «разумная середина»): перед отправкой заменять метками `⟦1⟧, ⟦2⟧…` только то, что состоит из цифр и где ошибка стоит денег — **телефоны, госномера, суммы с валютой, время, даты**; после перевода метки возвращаются на место. Email, ссылки, имена и прочий текст — **не маскировать**. Цель — чтобы модель не исказила числа (2 600 → 2 060, 18:30 → 8:30); бонусом телефоны не уходят наружу. Имена собеседников и id пользователей в запрос не передаются. Тест: «Позвони +7 701 234 56 78, госномер 777 ABP 05, оплата 2 600$, буду в 18:30» → в запросе к провайдеру — метки, в переводе — все четыре значения без изменений.
4. Определение языка оригинала: язык интерфейса отправителя по умолчанию; если текст явно на другом языке — определить моделью.
5. Перевод при отправке **только на язык собеседника(ов) чата** (kk/ru/zh/en — `users.language`), результат — в `translations[lang]`. Если язык получателя совпадает с оригиналом — перевод не нужен. Если получатель сменил язык позже — переводить старые сообщения лениво, при открытии чата.
6. **Шаблонные фразы** (`MessageTemplate`) — не переводить моделью: у шаблонов уже есть тексты на трёх языках, сообщение хранит `templateCode`.
7. Ошибка/таймаут провайдера (> 5 с): сообщение доставляется с оригиналом, `translationStatus = failed`, фоновая повторная попытка (3 раза).
8. DeepSeek хранит запросы в Китае и по умолчанию может использовать их для обучения — метки для цифр (п. 3а) обязательны; проверить в кабинете API, есть ли отказ от обучения, и включить. В логах бэкенда тексты сообщений не писать. Расход токенов и число запросов — метрика в админке (Настройки → Перевод: включён/выключен, модель, расход за 7 дней).
9. Лимит: до 60 сообщений в минуту на пользователя (защита от расходов).

### Flutter
10. Пузырь сообщения: текст на языке пользователя, подпись «Переведено · оригинал»; тап — показать оригинал. Если перевод не удался — оригинал и «Перевод недоступен · повторить».
11. Шаблонные кнопки над полем ввода: «Я на месте», «Загрузился», «Опаздываю на 1 час» и др. из справочника.

### Согласие
12. В тексте согласия на обработку данных (kk/ru/zh/en): текст сообщений чата передаётся сервису машинного перевода DeepSeek (КНР) для перевода (телефоны и номера заменяются метками).

## Готово, когда
- Водитель пишет по-русски — китайский логист видит по-китайски, и наоборот; казахский тоже.
- «Растаможка в СВХ, пломба 4417, буду в 18:30» — числа и время не искажены, термины переведены по словарю (тест на 10 фразах из словаря).
- При недоступном провайдере чат работает, сообщения доходят с оригиналом.
- Телефоны, госномера, суммы, время и даты не искажаются и не попадают в запрос к DeepSeek (тест на метки).
- Перевод можно выключить в админке одним переключателем — чат продолжает работать с оригиналами.
