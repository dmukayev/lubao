# 010 — Автоперевод сообщений в чате (ИИ-модель со словарём)

Статус: не начато · после 006

Решение — `docs/decisions.md` (2026-10-04, «Перевод в чате»). Голосовые сообщения — НЕ делать.

## Текущее состояние
`Message` уже хранит `originalText`, `originalLang`, `translations` (Json), но сервиса перевода нет — `translations` не заполняется. Чат — запросами, не в реальном времени (real-time — задача 011).

## Что сделать
### Бэкенд — модуль `translation`
1. Интерфейс `TranslationProvider.translate(text, from, to[], context) → {lang: text}` и реализация на ИИ-модели (Anthropic API; модель — из .env, по умолчанию быстрая/дешёвая). Провайдер можно сменить конфигом.
2. **Словарь терминов** `backend/src/translation/glossary.json`: термин → kk/ru/zh (растаможка, тентовка/тент, реф, TIR-книжка, CMR, СВХ, пломба, перегруз, простой, предоплата, наличка/безнал, госномер, прицеп, тягач, МЦПС, Нур Жолы и т. п. — минимум 40 терминов). Подставляется в промпт.
3. Промпт: «Переведи сообщение из чата водителя и логиста. Сохраняй числа, даты, время, суммы, валюты, госномера, телефоны и адреса без изменений. Не добавляй ничего от себя. Верни только перевод». Без истории переписки — только текущее сообщение (меньше данных уходит наружу).
4. Определение языка оригинала: язык интерфейса отправителя по умолчанию; если текст явно на другом языке — определить моделью.
5. Перевод при отправке сразу на два остальных языка из kk/ru/zh, результат — в `translations`. Если язык получателя совпадает с оригиналом — перевод не нужен.
6. **Шаблонные фразы** (`MessageTemplate`) — не переводить моделью: у шаблонов уже есть тексты на трёх языках, сообщение хранит `templateCode`.
7. Ошибка/таймаут провайдера (> 5 с): сообщение доставляется с оригиналом, `translationStatus = failed`, фоновая повторная попытка (3 раза).
8. Провайдер вызывается без сохранения данных на его стороне (проверить настройки аккаунта API); в логах бэкенда не писать тексты сообщений.
9. Лимит: до 60 сообщений в минуту на пользователя (защита от расходов).

### Flutter
10. Пузырь сообщения: текст на языке пользователя, подпись «Переведено · оригинал»; тап — показать оригинал. Если перевод не удался — оригинал и «Перевод недоступен · повторить».
11. Шаблонные кнопки над полем ввода: «Я на месте», «Загрузился», «Опаздываю на 1 час» и др. из справочника.

### Согласие
12. В тексте согласия на обработку данных (kk/ru/zh): сообщения чата передаются сервису машинного перевода для перевода, без хранения.

## Готово, когда
- Водитель пишет по-русски — китайский логист видит по-китайски, и наоборот; казахский тоже.
- «Растаможка в СВХ, пломба 4417, буду в 18:30» — числа и время не искажены, термины переведены по словарю (тест на 10 фразах из словаря).
- При недоступном провайдере чат работает, сообщения доходят с оригиналом.
