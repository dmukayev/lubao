# 064 — Исправления по ревью 059, 061, 062

Статус: не начато · **сейчас** (после 063). Оценка: 4–6 часов.
Ревью 2026-10-11 23:00. 061 и 062 приняты; **059 переоткрыта** (полный прогон был красный). Решение: `docs/decisions.md` → «Лента: пагинация в памяти — временно».

## 🔴
1. **Повтор груза между страницами роняет ленту** (`cargo_feed_screen.dart:56,162,240`; `cargos.service.ts:403,501`).
   - Сейчас: сортировка по `readyDate` (дата без времени) без вторичного ключа, подгрузка по `offset` дописывает страницы без проверки — повтор `id` даёт дублирующийся ключ карточки (красный экран в debug).
   - Исправить: последний ключ каждой сортировки — `id`; клиент отбрасывает уже показанные `id`.
   - Тест: две страницы при совпадающих датах не пересекаются.
2. **059 закрыта с красным `feed_filters` в полном прогоне** (SE и Android 360: «Found 0 widgets feedChipAll»), снимки 02–06 одинаковые.
   - Причина, по ревью: на узком экране с крупным шрифтом кнопки «Фильтры» и «Сортировка» занимают всю ширину, чипы «куда» за краем (п.5 ниже).
   - После исправлений: полный `scripts/e2e.sh`, новые снимки, где на каждом шаге видно действие; статус 059 → готово.

## 🟠 Лента (059)
3. **Старая подгрузка дописывается в новую ленту** (`cargo_feed_screen.dart:52-65,89-93`). Номер поколения (или `CancelToken`): ответ подгрузки, пришедший после смены фильтра или обновления, отбрасывать.
4. **Живой счётчик шторки** (`feed_filters.dart:223-231`): отменять или отбрасывать устаревшие ответы (номер запроса).
5. **Чипы «куда» не видны на SE / 360 с крупным шрифтом** (`feed_filters.dart:62-88`). «Фильтры» и «Сортировка» — иконками справа (с точкой, если активны), чипы — сразу видны слева и прокручиваются.
6. **«Куда» в строке активных фильтров** с ✕ (`feed_filters.dart:143-153`): страна, город, «Домой». Пустая лента не должна быть без видимой причины.
7. **«Откуда» не сохранять на устройстве** (`feed_filter.dart:133`): по умолчанию всегда город из статуса; выбранный вручную — только до смены статуса.
8. **Выбор кузова в шторке** — по профилям 048, а не по точному `bodyTypeId`; проверка «влезает в мою машину» (вес, объём, паллеты) сохраняется (`cargos.service.ts:391,412`).
9. **«Ближе погрузка»** — по расстоянию от города водителя до места погрузки (сейчас — по дате, `cargos.service.ts:507`).
10. **Мелочи ленты:**
    - `priceCurrency` проверять по списку (400 для неизвестной); нет курса — пометка в ответе, а не молчаливый пропуск фильтра;
    - при ошибке подгрузки — кнопка «Повторить», а не повтор на каждое событие прокрутки;
    - при старте — один запрос с сохранённым фильтром, без двойного;
    - «Показать 86 грузов» — с плюралом; убрать строки `'0'` / `'…'` из кода; удалить неиспользуемый ключ `feedFilterAnyCity`;
    - тесты сортировок `price_desc`, `distance`, UZS, без курса.
11. **Замер** `scripts/bench-feed.sh` — на реалистичных данных (разные города, кузова, компании, specs), цифры в статус.
