# 042 — «Живое приложение»: push, почта, WhatsApp-код, фоновые задачи

Статус: не начато · после 040. Оценка: 1,5 дня.
Опирается на 011 (бэкенд push готов, SDK нет), 018 (планировщик — не начато). Пилот — Казахстан: FCM + APNs; JPush — после пилота (не удалять заготовки).

## Что сделать
1. **Push-SDK в приложении:** `firebase_messaging` (Android/iOS) + APNs через Firebase; `registerDeviceToken()` при входе и смене токена; удаление токена при logout; обработка тапа по push → экран (чат/сделка/анонс) через go_router deep link; foreground — локальное уведомление. Разрешение запрашивать после первого осмысленного действия (отклик/анонс), не на старте. Push с кнопками «Да / Уехал» для правила свежести (040 п.4). Сборка для КНР без Firebase — отдельный flavor `cn` (заглушка, не реализовывать).
2. **Почта:** `EmailProvider` с SMTP (nodemailer) — env `SMTP_HOST/PORT/USER/PASS/FROM`; шаблоны на 4 языках (приглашение, сброс пароля, подтверждение email, «Договорились?»-дайджест). Приглашение — **https-ссылка** `https://<APP_HOST>/invite/<token>` (universal link / app link; на вебе открывает экран принятия), `lubao://` убрать. Проверка доставки в gmail/mail.ru/qq.com — в итоге задачи.
3. **WhatsApp-код входа** (канал в `sms`-абстракции): Meta Cloud API, шаблон authentication с кнопкой копирования; env `WHATSAPP_TOKEN/PHONE_ID/TEMPLATE`; порядок: WhatsApp → при ошибке «нет WhatsApp»/таймауте 10 с → SMS автоматически; кнопка «Не пришло? Отправить SMS». Без ключей — канал выключен, работает SMS (Mobizon). Лимиты как у SMS.
4. **Планировщик (018):** `@nestjs/schedule` + BullMQ с блокировкой в Redis; задачи идемпотентны:
   - курс НБ РК ежедневно 10:00 Алматы + при старте, если курса на сегодня нет; ручная правка в админке;
   - «Договорились?» через 2 ч после `contact_event` (push с кнопками «Да → выбрать груз / Нет»);
   - свежесть анонсов (040 п.4) — все таймеры;
   - архив грузов через 3 дня после `readyDate` (не 48 ч), истечение откликов `INVITED` через 24 ч;
   - удаление геопозиций старше 30 дней; чистка просроченных сессий/кодов.
5. **WeCom:** сообщения чата тоже уходят в WeCom-бот компании (сейчас только NEW_RESPONSE/DEAL_STATUS — `chats.service.ts:300` без `companyId`). Текст на языке компании.
6. Все письма/пуши/WeCom — **без «Хоргос»**, город из справочника; тексты в 4 языках через l10n-таблицу на сервере.
7. Тесты: планировщик (идемпотентность, блокировка), фолбэк WhatsApp→SMS, формирование deep link; живая проверка push на реальном Android и iPhone (ручной шаг — скриншоты в итог); e2e: push-токен регистрируется (мок).

## Готово, когда
- Водитель с закрытым приложением получает «Вас выбрали» и «Ещё ищете груз?» с кнопками; тап открывает нужный экран.
- Логист получает письмо-приглашение по https-ссылке и письмо сброса пароля.
- Код входа приходит в WhatsApp, без WhatsApp — SMS.
- Курс обновляется сам; «Договорились?» приходит через 2 ч после звонка; анонсы гаснут по правилу.
