1. **Приложение:**
   - убрать поле, строку и подпись «паллеты» везде:

2. **Админка:**
   - убрать паллеты из карточки водителя и машины;
   - справочник шаблонов кузова — без колонки паллет;
   - профили кузова — без поля паллет.

4. **ARB:** ключи с паллетами удалить во всех 4 языках, если они больше нигде не используются.
5. **Тесты:**
