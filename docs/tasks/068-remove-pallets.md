# 068 — Паллеты скрыты; включаются галочкой в админке

Статус: не начато.
Решение: `docs/decisions.md` → «2026-10-13 · Паллеты скрыты, включаются галочкой в админке». Владелец: «паллеты нигде не нужны — скрой это поле».
Оценка: 3–4 часа.

## Что сделать
1. **Справочник типов кузова:**
   - в профиле новый флаг `showPallets` (по умолчанию `false`);
   - миграция: всем существующим типам кузова `false`;
   - в админке («Справочники → Типы кузова») — галочка «Паллеты» с подсказкой «Показывать водителям и логистам поле паллет и учитывать его в подборе».
2. **Флаг приходит в приложение вместе со справочником.** Если у кузова `showPallets = false`, паллет нет нигде:
   - гараж и добавление машины — шаблоны «Стандарт ~90 м³», без «/ 33 паллеты»;
   - форма груза, лента, карточка груза, отклики, «Кто свободен», карточка водителя (067);
   - тексты «Поделиться» и push;
   - админка — карточка водителя и машины.

   Если `true` — как сейчас.
3. **Бэкенд:**
   - отсев ленты (`profile-fit.ts`, `body-size.ts`) и проверка догруза (`vehicle-load.ts`) учитывают паллеты только при `showPallets = true`, иначе — вес и объём;
   - `palletCount` / `palletsEuro` в DTO необязательные;
   - колонки и данные в базе не трогать.
4. **Тесты:**
   - юнит: при выключенном флаге паллеты не отсеивают; при включённом — отсеивают как раньше;
   - e2e: в гараже и форме груза нет слова «паллеты» (флаг выключен по умолчанию); в админке галочка есть;
   - старые проверки паллет (`garage_vehicle_test`, `drivers_at_point_screen_test`) поправить.

## Готово, когда
- По умолчанию нигде в приложении нет «паллет».
- Галочка в админке возвращает поле для выбранного кузова без новой версии.
- `scripts/e2e.sh` зелёный на iPhone SE и Android 360 (крупный шрифт) + Chrome.
