# 004 — Регистрация водителя

Статус: не начато

## Цель
Водитель регистрируется примерно за минуту, всё выбирается кнопками.

## Флоу (после SMS-кода из задачи 003)
`Имя` → `Машина` → `Куда готов ехать` → главная

1. **Имя** — одно поле.
2. **Машина** — эталон `design/screens/04-register-vehicle.png`: тип кузова плитками с картинками, грузоподъёмность кнопками (10/15/20/25 т), допуски чипами (TIR, CMR, ADR, разрешение РФ). Справочники — с бэкенда.
3. **Куда готов ехать** — эталон `design/screens/05-register-directions.png`: переключатель «Любое направление», список стран с чекбоксами (у Казахстана — раскрытие регионов), «Мой дом» (город из справочника). Кнопка показывает «Выбрано N страны · Дальше».

Индикатор шагов вверху. Прогресс сохраняется: закрыл приложение — продолжает с того же шага.

## НЕ делать в регистрации
Документы и фото — это задача 005 (профиль).

## Готово, когда
- Новый водитель проходит флоу и попадает на главную.
- Данные сохранены в drivers, vehicles, driver_directions.
- Экраны совпадают с эталонами.
