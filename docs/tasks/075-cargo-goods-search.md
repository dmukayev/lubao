# 075 — «Что везёте?»: поиск товара по названию и коду ТН ВЭД, свой вариант

Статус: не начато.
Решение: `docs/decisions.md` → «2026-10-13 · «Что везёте?» — поиск по названию и коду ТН ВЭД». Владелец: «давай так и сделаем».
Оценка: 2–3 дня.

## Данные
1. **`hs_codes`** — полный HS-6: `code` (6 цифр), `chapter` (2), `heading` (4), `name` JSON {kk, ru, zh, en}.
   - Источники: ТН ВЭД ЕАЭС (ru; kk — если есть официальный), таможенный тариф КНР (zh).
   - **Проверить лицензию текстов:** официальные акты ЕАЭС и КНР обычно можно использовать, а английские описания HS у WCO под авторским правом. Если en нельзя взять свободно — en делаем своим переводом ru. Источники и вывод записать в статус задачи.
   - Загрузка — скрипт импорта из файла в `backend/prisma/data/` (не из сети при сидировании).
2. **`goods`** — популярные товары:
   - `name` JSON (4 языка), `synonyms` JSON (массивы слов по языкам), `hsCode` (nullable), `categoryId`, `suggestedBodyTypeId` (nullable), `isDangerous`, `sortOrder`, `isActive`;
   - стартовый список ~150–300 позиций — то, что идёт из Китая через Хоргос (плитка, сантехника, одежда, обувь, электроника, бытовая техника, мебель, запчасти, шины, овощи/фрукты, стройматериалы, металл…). Черновик составляет Claude Code, правит владелец/Болат в админке.
3. **Глава HS → категория:** таблица соответствия 97 глав и 8 категорий (например, 01–24 → Продукты, 25–27/68–70 → Стройматериалы, 72–83 → Металл, 84–85 → Оборудование, 50–67 → ТНП/текстиль, остальное → Другое). Правится в админке.
4. **Груз:**
   - новые поля `goodsId` (nullable), `goodsText` (nullable, свой вариант), `hsCode` (nullable);
   - `categoryId` остаётся обязательным: из товара / кода, иначе выбирает логист;
   - миграция проверена на базе с демо-данными (старые грузы — только категория).

## Поиск
5. **`GET /goods/search?q=`:**
   - только цифры (2–6) → по префиксу кода (`hs_codes` + `goods.hsCode`);
   - иначе — по `goods.name` + `synonyms` на всех языках (без учёта регистра, в том числе по началу слова), затем по `hs_codes.name`;
   - не больше 20 результатов: сначала популярные, потом официальные;
   - быстро (< 100 мс): индексы `pg_trgm` или аналог.
6. **Частые товары компании** (последние 10 разных) — `GET /goods/recent`, показываются до ввода.

## Форма груза
7. **Поле «Что везёте?»** вместо 8 кнопок категорий:
   - подсказки при вводе: «Плитка керамическая · 6907 · Стройматериалы»;
   - выбрал → поле заполнено, категория подставлена (её видно и можно поменять); если у товара есть подсказка кузова и кузов ещё не выбран — подставить; ADR — пометка «Опасный груз»;
   - последняя строка всегда «Добавить: „<что ввёл>“» → свой текст; если категорию не определить — 8 кнопок прямо под полем;
   - пустое поле → ошибка по 072 («Укажите, что везёте»).
8. **Изменение / повтор груза** — поле заполнено прежним значением.

## Где показывать
9. Лента, карточка груза, «Мои рейсы», сделка, грузы логиста (065/071), «Поделиться», push: **простое название на языке читателя** вместо названия категории («Плитка · 20 т · Тент»). Свой текст — через модуль перевода, как сообщения чата (оригинал + переводы). Код HS — мелко серым в карточке груза. Старые грузы без товара — как сейчас, категория.

## Админка
10. Справочники:
    - «Товары» — список, поиск, правка названий/синонимов/кода/категории/кузова/ADR;
    - «Коды HS» — только просмотр и правка названия;
    - «Главы → категории».
11. «Новые слова» — свои варианты логистов с количеством; кнопка «Добавить в товары» (подставляет текст).

## Тесты
12. Юнит:
    - поиск по коду и по названию на 4 языках;
    - выведение категории из главы;
    - свой вариант без кода.
13. **e2e:**
    - логист вводит «6907» → выбирает плитку → категория «Стройматериалы»;
    - вводит «瓷砖» → находит то же;
    - вводит несуществующее → «Добавить» → груз опубликован;
    - водитель видит «Плитка» в ленте на русском.

## Готово, когда
- Груз можно опубликовать, найдя товар по коду или названию, или своим текстом.
- Водитель видит конкретный товар на своём языке.
- `scripts/e2e.sh` зелёный на iPhone SE и Android 360 (крупный шрифт) + админка в Chrome.
