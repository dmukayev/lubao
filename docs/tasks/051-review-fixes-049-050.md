Статус: не начато · **сейчас**. Оценка: 1–2 часа. Ревью 2026-10-08 по коммитам `48ded252…aeebadc4`.
Решение: `docs/decisions.md` → «Вход без кода через бот Telegram» — **отменено**, вход водителя только по коду (Telegram Gateway / WhatsApp / SMS).
