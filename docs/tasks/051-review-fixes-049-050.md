## 🔴 Безопасность входа через Telegram
1. **Вход по чужой ссылке одной кнопкой.** Сейчас ссылку `t.me/<bot>?start=<nonce>` может создать кто угодно и прислать водителю («зайди по ссылке, там грузы»). Если водитель уже входил через бота (`telegramUserId` известен), `onStart` сразу ставит READY без вопросов: водитель нажал «Старт» — злоумышленник вошёл в его аккаунт. Для нового водителя то же самое, только нужно ещё нажать «Поделиться номером».
   Исправить:
   - **всегда** спрашивать подтверждение в боте, и для известного Telegram тоже: «Вход в Lubao на устройство «<deviceName>, <platform>», <время>. Это вы нажали «Войти через Telegram» в приложении?» с inline-кнопками «Да, это я» / «Нет» (`callback_query`);
   - READY ставить только после «Да». На «Нет» — nonce отменить, в журнал `TELEGRAM_LOGIN_REJECTED`;
   - текст предупреждения на 4 языках: «Не нажимайте, если ссылку вам прислали».
   - Тест: известный `telegramUserId` + `/start` без «Да» → опрос остаётся PENDING.
2. **Опрос привязать к устройству.** `POST /auth/telegram/start` возвращает, кроме `nonce`, отдельный `pollSecret`. Он не попадает в t.me-ссылку, а `GET /auth/telegram/:nonce` требует его в заголовке. Иначе токены заберёт любой, кто увидел ссылку (переслали, скриншот).
3. Секрет webhook сравнивать через `timingSafeEqual`.

## 🟠 Работает, но ломается в жизни
4. **Ложное «Ссылка устарела» после успешного входа.** `Timer.periodic` с async-колбэком: если ответ дольше 2 с, запросы идут внахлёст. Один получает READY, второй 409, и водитель видит ошибку, хотя уже вошёл. Кроме того, **любая** ошибка (сеть при возврате из Telegram, 429) обрывает ожидание.
   Исправить: последовательный цикл (следующий запрос только после ответа), обрывать только на 410/409, сеть и 5xx — повторять. После READY ошибки не показывать.
5. **Кнопка «Открыть приложение» в боте ведёт на несуществующую страницу** `APP_PUBLIC_URL/login/telegram-done`: маршрута нет ни в приложении, ни на сайте. Схема `lubao://` тоже не настроена.
   Исправить:
   - App Link / Universal Link на `/login/telegram-done`: Android — `intent-filter` рядом с `/invite`; iOS — associated domains;
   - для веба — простая страница «Готово, вернитесь в приложение»;
   - запасной вариант — убрать кнопку и написать текстом «Вернитесь в Lubao».
6. **Опрос и общий лимит.** Проверить, что 150 опросов за 5 мин с одного IP (несколько водителей за одним NAT на стоянке) не упираются в `THROTTLE_LIMIT`. Если упираются — для `GET auth/telegram/:nonce` свой лимит.
7. Номер из Telegram: `+${digits}` заменить на `normalizePhone`, тот же путь, что после SMS. Если правила номеров для водителей ограничены, проверять так же, как в `request-code`, и отвечать в боте понятным текстом.
