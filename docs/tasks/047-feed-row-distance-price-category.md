## Что сделать
### Данные
1. **Категория груза:** справочник `cargo_categories` (`code`, `name` {kk,ru,zh,en}, `sortOrder`, `isActive`; сид: стройматериалы, продукты, оборудование, ТНП/текстиль, металл, негабарит, опасный (ADR), другое) — админка CRUD. `Cargo.categoryId` обязателен при публикации (миграция: существующим — «другое»).
2. **Расстояние по дороге** — **OSRM в своём контейнере** (решение 2026-10-08): сервис `osrm` в `infra/docker-compose.yml` (образ `osrm/osrm-backend`), карта — выдержка OSM Казахстан + Кыргызстан + Узбекистан + приграничные области РФ и СУАР (Geofabrik, скрипт `infra/osrm/prepare.sh`: скачать `.osm.pbf`, `osrm-extract` с профилем `car`, `osrm-contract`; данные в volume, не в репозитории). Бэкенд: `DistanceService.roadKm(fromCity, toCity)` → `GET /route/v1/driving/...?overview=false`, результат в `city_distances` (`fromCityId`, `toCityId`, `km`, `source=osrm`, `computedAt`), считается один раз на пару, при недоступности OSRM — «—» и повтор планировщиком. Без Google и внешних API. Таймаут 5 с, OSRM только во внутренней сети. В `docs/release.md` — подготовка карты на проде (разовая, ~30 мин, ~2 ГБ).
3. **₸/км** = цена в валюте груза / км; для USD/CNY — пересчёт по курсу НБ РК в тенге для подсказки «рынок». Хранить `pricePerKm` в валюте груза.
4. **Статистика цен** `price_points`: при публикации (`kind=LISTED`, только проверенные компании) и при `DELIVERED` (`kind=DEAL`); поля: `fromCityId`, `toCityId`, `bucket` (KZ / CIS / CN_FAR — по стране назначения), `tonnageClass` (≤5 / ≤10 / >10 → 5/10/20), `pricePerKm` в KZT, `createdAt`. Дедуп: одна пара водитель–компания по маршруту за 30 дней = одна точка. Планировщик раз в сутки считает медиану и P25–P75 за 30 дней по (from, to, bucket, tonnageClass) при ≥ 5 точках → `route_price_stats`.

Статуса «Опубликован» нет. Плашки — только состояние по отношению к водителю (045 п.2). Размеры шрифта — не более трёх.

8. Админка: экран «Цены по маршрутам» — таблица (маршрут, корзина, тоннаж, медиана, P25–P75, точек, из них сделок), фильтры, выгрузка CSV.

## Готово, когда
- В ленте каждый груз показывает категорию, км и ₸/км по эталону 28; статуса «Опубликован» нет.
- Груз без категории опубликовать нельзя; расстояние считается само для городов справочника.
- Через 5+ сделок по маршруту логист при публикации видит медиану, водитель в карточке — диапазон рынка.
