Статус: ✅ 🔴 и 🟠 готовы 2026-10-09; 🟢 не делались (см. «Статус по пунктам»).

## 🔴
1. **052: новый водитель по ссылке не попадает на груз.** `share_links.dart:23,62` — обработчик срабатывает только при появлении сессии, а у нового водителя в этот момент ещё нет профиля (`/driver/register`). После регистрации `consume` больше не вызывается. Вызывать `consume` и при переходе `driver == null → driver != null` (или явно после регистрации). e2e: **новый** водитель по ссылке → регистрация → экран этого груза.
2. **054: после удаления аккаунта фото профиля остаётся** и отдаётся компаниям (`account-deletion.service.ts:66,88-92,114-118`).
   - В транзакции: `avatarFileKey = null`, `avatarUpdatedAt = null`.
   - После коммита — удалить файл миниатюры.
   - Тест: после удаления `/drivers/:id/avatar` → 404.
3. **056: после отменённой сделки водителя нельзя выбрать снова.** У сделки `responseId @unique`, и старая отменённая сделка держит отклик → «Выбрать» / «Нашёл в Lubao» падает 409 с неправдивым текстом (`responses.service.ts:259-263,223,571-575,445-458`).
   - При отмене сделки отвязывать её от отклика (`responseId` nullable, обнулять при отмене; миграция для существующих отменённых).
   - Тест: сделка отменена → водитель снова откликнулся → логист выбрал → новая сделка.
