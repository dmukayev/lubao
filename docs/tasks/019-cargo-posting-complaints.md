# 019 — Публикация груза (логист) и жалобы / блокировка

Статус: не начато · после 012 и 016

## Публикация груза — что не хватает (ревью 2026-10-04)
`post_cargo_screen.dart` умеет: назначение, кузов, объём, вес, цена + валюта, дата, фото. Нет:
1. **Точки погрузки** (терминал Хоргоса) — сейчас грузу не выбрать терминал в форме.
2. **Нужных допусков** (`requiredPermitIds`, задача 016) — чипами TIR / CMR / ADR / разрешение РФ.
3. **Город назначения** — сделать обязательным для KZ (нужен для секции «Близко к дому»), для других стран — по желанию.
4. **«Повторить груз»** — копия прошлого груза с новой датой (логисты возят одни и те же направления).
5. Подсказка цены: «Похожие грузы Хоргос → Ташкент за 30 дней: ¥15 000–18 000» (по своим данным, когда их ≥ 5).
6. Блокировка публикации для непроверенной компании и сбор недостающих полей (задача 012).

## Жалобы и блокировка — от пользователей
В схеме есть `Complaint`, экран жалоб в админке есть, но **пожаловаться из приложения нельзя**.
7. Кнопка «Пожаловаться» в карточке водителя, компании, груза и в чате (меню «⋯»): причины — мошенничество / не приехал / неверные данные груза / грубость / другое + комментарий. Языки — kk/ru/zh/en.
8. «Заблокировать»: пользователь больше не видит грузы/анонсы и сообщения заблокированного (личный чёрный список, `user_blocks`).
9. Админка: в жалобе — ссылка на профиль, история сделок и чат (если жалоба из чата); действия «Предупредить», «Заблокировать в Lubao», «Отклонить жалобу». Блокировка в Lubao разлогинивает пользователя (сессии из 006) и скрывает его контент.
10. Три жалобы «мошенничество» от разных пользователей — автоматически скрыть контент до решения админа.

## Готово, когда
- Логист публикует груз с терминалом погрузки и допусками; повтор груза — в 2 нажатия.
- Водитель жалуется на груз из карточки; жалоба видна в админке с контекстом.
- Заблокированный админом пользователь не может войти, его грузы/анонсы не видны.
