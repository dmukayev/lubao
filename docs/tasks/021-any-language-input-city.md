  органично придут через «Нет моего города» + модерацию.
- **Валидация имени**: `\p{L}` + пробел/дефис/апостроф/точка, 2-80 символов,
  без цифр — идентичный regex на бэкенде (`IsPersonName` decorator) и на

  молчаливого отказа — первый inline-validation механизм в кодовой базе
  (`AppTextField.errorText`).
- **Клавиатура (п.2 задачи)**: в коде не было и нет ни одного
  `inputFormatters`, блокирующего ввод — подтверждено и ревью кода, и
  живыми виджет-тестами (ввод «Ерлан Қасымов», «Ли Вэй», «李伟», «John
  O'Neil» проходит в поле имени без искажений). На Android-эмуляторе живой
  тест показал: `adb shell input text` (эмуляция физической клавиатуры по

  скан-кодами; реальные экранные клавиатуры (Gboard) используют другой
  путь (`commitText`, прямой Unicode) и этим ограничением не связаны. Это

## Что сообщил владелец (2026-10-04)
При регистрации водителя «не могу набрать имя на кириллице и написать город». Должно работать для всех языков: kk, ru, zh, en.

## Причины (ревью кода)
1. **Город** (`driver_setup_screen.dart`, `Autocomplete<CountryCityOption>`):
   - ищет только по названию **на текущем языке интерфейса** (`label` из `countryCityOptions(locale)`): интерфейс на русском — «Shymkent» или «Шымкент» по-казахски не найдётся; интерфейс на английском — «Шымкент» не найдётся;
   - в справочнике мало городов (`seed.ts`: города республиканского значения, областные центры, несколько зарубежных) — водитель из Жаркента, Талгара, Сарыагаша **не найдёт свой город вообще** и не сможет завершить регистрацию (`_homeCityId == null` → `_submit` молча ничего не делает);
   - при неудаче нет никакого сообщения — кнопка просто не срабатывает.
2. **Имя:** в коде ограничений на ввод нет (`AppTextField` без `inputFormatters`). Вероятная причина — тестирование на **Android-эмуляторе**: физическая клавиатура компьютера передаёт в эмулятор только латинские коды клавиш. Проверить на эмуляторе с экранной клавиатурой (Gboard с добавленными русской/казахской раскладками) и на реальном телефоне. Если на реальном устройстве тоже не вводится — найти причину и исправить.

2. Нормализация запроса и названий: регистр, `ё→е`, казахские буквы → русские аналоги для сравнения (`қ→к, ғ→г, ң→н, ө→о, ұ→у, ү→у, һ→х, і→и, ә→а`), латиница ↔ кириллица по простой транслитерации (Shymkent ≈ Шымкент, Almaty ≈ Алматы), пробелы/дефисы.
3. Совпадение по началу слова — выше, по вхождению — ниже. Первые 20 результатов.

### Город, которого нет в справочнике
4. Последний пункт списка: **«Нет моего города»** → поле «Населённый пункт» (свободный ввод, любой язык) + выбор **области/региона** из справочника (обязательно). Сохраняется как город со статусом `PENDING` (`City.isUserSubmitted = true`, `submittedByUserId`), привязанный к выбранному региону — регистрация сразу продолжается.

### Сообщения и проверка
6. Если не заполнены обязательные поля — подсветить поле и показать текст ошибки (ARB), а не молча не реагировать.
7. Имя: допускать буквы любых алфавитов (`\p{L}`), пробел, дефис, апостроф, точку; 2–80 символов; без цифр. То же правило — на бэкенде.
8. То же для всех полей свободного ввода в приложении (имя логиста, город компании, комментарии): никаких ограничений по алфавиту.
9. Тесты: виджет-тест ввода «Ерлан Қасымов», «Ли Вэй», «李伟», «John O'Neil» в поле имени; поиск города «шымкент», «Shymkent», «奇姆肯特» (если перевод есть) находит Шымкент; «Нет моего города» → регистрация завершается.

## Готово, когда
- На реальном Android-телефоне и в эмуляторе с экранной клавиатурой имя вводится на кириллице (включая казахские буквы), китайском и латинице.
- Город находится, как бы его ни ввели (язык интерфейса не важен); водитель из города не из справочника завершает регистрацию.
- Незаполненное обязательное поле показывает понятную ошибку.
