# 060 — Скорость: вкладки без переходов и перезагрузки, кэш, проверка в release

Статус: не начато · после 058, до 059. Оценка: 3–5 часов.
Откуда: владелец 2026-10-10 — при переходе между вкладками видны чёрные полосы, приложение кажется медленным.

Причины (по коду):
- Нижнее меню (водитель и логист) — обычный `ShellRoute` (`app_router.dart:146,180`). Каждая вкладка — новая страница с переходом по умолчанию. На Android за уезжающей страницей виден чёрный фон навигатора — отсюда чёрные полосы.
- Экран вкладки строится заново, данные грузятся заново, прокрутка теряется.
- Владелец смотрит сборку `flutter run` в режиме debug — она в разы медленнее настоящей.

## Что сделать
1. **Вкладки — `StatefulShellRoute.indexedStack`** у водителя и логиста:
   - переключение мгновенное, без анимации и чёрных полос;
   - каждая вкладка остаётся в памяти, позиция прокрутки сохраняется;
   - повторное нажатие на активную вкладку — прокрутка наверх.
   - Ссылки из push и `/c|co|d` по-прежнему открывают нужный экран.
2. **Переходы на вложенные экраны** (карточка груза, чат, сделка) — фон страницы всегда `AppColors.bg`; без чёрного на Android и iOS, в светлой и тёмной теме.
3. **Сначала то, что уже есть, потом обновление.** Списки (лента, «Мои рейсы», чаты, грузы логиста) при возврате показывают прошлые данные сразу и тихо обновляются (Riverpod keepAlive / кэш последнего ответа). Пустой экран с крутилкой — только при самом первом открытии; вместо крутилки — заготовки карточек (скелет).
4. **Картинки:** аватары и фото машин — кэш на диске (`cached_network_image` или аналог без Google), миниатюры, а не оригиналы, в списках.
5. **Замер:**
   - сборка `--release` (или `--profile`) на Android 360 и iPhone SE;
   - время до первой ленты после запуска; переключение вкладок; прокрутка ленты из 200 грузов — без рывков (DevTools, кадры > 16 мс);
   - цифры записать в статус.
   - В `docs/release.md` и в инструкции запуска: «смотреть скорость только в `--release`».
6. **e2e:** шаг «переключить все вкладки туда-обратно» на обеих платформах — прокрутка сохраняется, вкладка не грузится заново (нет повторного запроса за 2 с).

## Готово, когда
- Вкладки переключаются мгновенно, без чёрных полос, с сохранённой прокруткой.
- Возврат на экран показывает данные сразу.
- Замеры в release — в статусе; `scripts/e2e.sh` зелёный на iPhone SE и Android 360 dp + Chrome.
