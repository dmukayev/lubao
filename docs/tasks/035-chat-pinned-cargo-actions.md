# 035 — Чат: закреплённая карточка груза/сделки, отклик и выбор водителя прямо из переписки

Статус: сделано (п.1, 2, 4, 5 — целиком; п.3 — частично, см. итог внизу файла) · **после 032, до 033** (ядро сценария «договорились»). Оценка: 1,5–2 часа.
Решение: `docs/decisions.md` → «Отклик и сделка — и из чата» (2026-10-06). Эталон верха чата — `design/screens/03-chat.png` (карточка груза над перепиской).

## Проблема (ревью 2026-10-06)
П.3 задачи 017 («карточка груза/сделки закреплена сверху чата, там же — „Подтверждаю перевозку“») **не сделан**, хотя 017 отмечена готовой: в `chat_screen.dart` нет ни карточки, ни кнопок. Откликнуться можно только из карточки груза; выбрать водителя — только в списке откликов. Люди договариваются в чате — а сделка из чата не оформляется, значит не будет рейтинга, «Проверенного», защиты, истории рейсов.

## Что сделать
1. **Закреплённая карточка над перепиской** (если у чата есть груз): маршрут (город погрузки → назначение), цена + пересчёт, кузов/вес, статус. Тап — карточка груза. Сворачивается в одну строку при прокрутке.
2. **Кнопки в карточке — по роли и состоянию:**
   | Кто | Состояние | Кнопка |
   |---|---|---|
   | Водитель | не откликался | **«Готов взять»** (= отклик, тот же `POST /responses`) |
   | Водитель | откликнулся | «Отклик отправлен» (неактивна) + «Отозвать» |
   | Логист | водитель откликнулся или просто пишет | **«Выбрать этого водителя»** → тот же диалог, что в откликах (связка машин водителя, кузов/тоннаж, «водитель поедет в: <город погрузки>») → сделка `SELECTED`; если отклика не было — создаётся автоматически |
   | Водитель | сделка `SELECTED` | **«Подтверждаю перевозку»** (проверка верификации водителя и связки — как в сделке) |
   | Оба | сделка дальше | статус сделки и следующее действие («Загружен», «В пути», «Доставлено») — те же, что в карточке сделки |
3. Чат без груза (логист написал водителю из «Кто будет»): у логиста вместо карточки — кнопка «Предложить груз» → выбор из своих опубликованных → в чат уходит карточка груза, чат привязывается к грузу (если по паре водитель+компания+груз чата ещё нет; иначе — переход в существующий, история сохраняется).
4. Каждое действие из чата → системное сообщение в переписке на языке получателя: «Ерлан готов взять груз», «Логист выбрал вас для перевозки», «Перевозка подтверждена».
5. Права: «Выбрать» — только сотрудник компании-владельца груза; «Готов взять» — только водитель этого чата; все проверки — на сервере (переиспользовать существующие сервисы откликов/сделок, не дублировать логику).
6. ARB на 4 языках; ключи `Key(...)` на кнопках — для сценариев 034 (добавить шаг: договорились в чате → сделка из чата).

## Готово, когда
- Водитель в чате по грузу жмёт «Готов взять» — у логиста отклик появился и в списке откликов, и в чате.
- Логист в чате жмёт «Выбрать этого водителя» — создаётся сделка, водитель видит в чате «Подтверждаю перевозку».
- Логист из чата без груза предлагает груз — чат привязан к грузу, карточка вверху.
- Сценарий в 034 проходит путь «чат → сделка» без перехода в другие экраны.

## Итог (2026-10-05/06)

**Переиспользование (п.5), как и просила задача** — ни одного нового
бизнес-правила, только недостающие проводки к уже существующим сервисам:
`cargoRepository.respond/updateResponseStatus/inviteDriver` — те же вызовы,
что в `cargo_detail_screen.dart`/`cargo_responses_screen.dart`. Новое —
строго инфраструктурное:
- `ResponsesService.withdraw(responseId, driverId)` + `POST
  /responses/:id/withdraw` (водитель, только свой отклик, только
  `PENDING` → `CANCELLED`) — статус `CANCELLED` уже был в схеме с задачи
  017, просто не использовался ни одним путём.
- `ChatsService.toThreadDto` — новые `cargoResponseId`/`cargoResponseStatus`
  (отклик ЭТОЙ пары водитель+груз, если груз у чата есть) — решают, какую
  кнопку показывать, без отдельного запроса.
- `ChatsService.attachCargo` + `PATCH /chats/:id/cargo` — «Предложить
  груз» из чата без груза: если по паре водитель+компания+ЭТОТ груз чат
  уже есть — переходим в него (история сохраняется), иначе довешиваем
  `cargoId` на текущий чат (не создаём новую строку).
