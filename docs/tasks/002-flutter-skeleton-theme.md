# 002 — Каркас Flutter, тема и UI-кит

Статус: не начато

## Цель
Приложение запускается на эмуляторе и в браузере, выглядит как макеты, все строки на трёх языках.

## Что сделать
1. `apps/lubao_app` (iOS, Android, Web) и `apps/lubao_admin` (Web), общий пакет `packages/lubao_core`.
2. Riverpod, go_router, Dio. Базовый API-клиент к бэкенду.
3. Локализация: ARB для kk/ru/zh, автоопределение по языку устройства, fallback ru, ручное переключение (сохранять выбор).
4. Тема строго по `design/DESIGN.md`: полностью свой `ThemeData`, токены цветов, типографика. Шрифт Onest вшит в assets (НЕ google_fonts).
5. UI-кит из раздела «Компоненты» DESIGN.md + страница-витрина компонентов (только в dev).
6. Каркас навигации водителя: 4 вкладки (Главная, Грузы, Чаты, Профиль) — пустые экраны.
7. Иконки — `lucide_icons`.

## Готово, когда
- Приложение запускается на Android-эмуляторе и в Chrome.
- Смена языка устройства меняет язык интерфейса; казахские буквы отображаются шрифтом Onest.
- Витрина компонентов визуально совпадает с макетами в `design/screens/`.
- В коде нет захардкоженных строк UI.

Экраны пока не делать — только тема, компоненты и навигация.
