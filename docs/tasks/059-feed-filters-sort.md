# 059 — Лента водителя: фильтры, сортировка, чипы «куда»

Статус: не начато · после 058. Оценка: 1–1,5 дня.
Решение: `docs/decisions.md` → «Что берём у Sarbon», пункт «Лента» (2026-10-10). Сохраняется текущая логика (045, 047, 048): статус «Ищу груз из <город>» решает, откуда погрузка; отсев по кузову — как сейчас.

## Что сделать
1. **Чипы «куда» над лентой.**
   - Строятся из реальных грузов текущей выборки: «Все 42 · Домой 8 · Россия 15 · Узбекистан 6 · Алматы 9»; «Домой» всегда первым, если есть.
   - Одно нажатие — фильтр по стране или городу выгрузки.
2. **Фильтры** (кнопка рядом с чипами; шторка с живым счётчиком «Показать 86 грузов»):
   - откуда — страна и город (по умолчанию — из статуса);
   - куда — страна и город;
   - кузов — по профилям 048, «можно несколько»; по умолчанию — моя машина;
   - вес от–до (т);
   - цена от–до в выбранной валюте (пересчёт через ₸);
   - **₸/км от**;
   - дата погрузки: любая / сегодня / 3 дня / неделя;
   - «только с авансом»;
   - «Сбросить».
   - Фильтр запоминается на устройстве. Над лентой — строка активных фильтров с ✕.
3. **Сортировка:**
   - по умолчанию — как сейчас: город погрузки → домой → выбранные страны → по дате;
   - дешевле / дороже — в ₸;
   - **выгоднее ₸/км**;
   - ближе погрузка;
   - короче / длиннее маршрут;
   - новые.
4. **Бэкенд:** параметры фильтра и сортировки в `GET /cargos`; пагинация на стороне базы, а не в памяти — сейчас вся выборка сортируется в памяти (`cargos.service.ts` feed); индексы по нужным полям. Счётчик для шторки — тот же запрос с `count`.
5. **Грузы из других городов** (не город погрузки и не рядом) — по умолчанию свёрнуты строкой «Грузы из других городов · 240 → показать»; если в фильтре «откуда» выбран другой город — показывать его.
6. **Бесконечная прокрутка** вместо «Ещё».
7. **Веб логиста:** те же фильтры в «Водители → Кто свободен» не трогать; эта задача — только лента водителя.
8. ARB, 4 языка.
9. **Тесты:**
   - бэкенд — каждый фильтр и сортировка, счётчик, пагинация, ₸/км в разных валютах;
   - e2e — чип «Россия» → только грузы в Россию; фильтр кузов + вес → счётчик совпадает со списком; сортировка ₸/км; свёрнутые «другие города».

## Готово, когда
- Водитель за 1–2 нажатия видит грузы отсюда туда, куда ему надо, и может отсортировать по выгоде (₸/км).
- Лента не тормозит при 1 000+ грузов (замер в статусе).
- `scripts/e2e.sh` зелёный на iPhone SE и Android 360 dp + Chrome.
