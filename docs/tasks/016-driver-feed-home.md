# 016 — Лента грузов водителя и главная по макету 01

Статус: не начато · после 015

## Проблема (ревью 2026-10-04)
- `GET /cargos` отдаёт **все** опубликованные грузы, сортировка — на клиенте (`sortCargoFeed`). С ростом числа грузов это медленно и тяжело для мобильного интернета на границе.
- «Домой» считается по **стране**: для казахстанского водителя все грузы в Казахстан — «домой». По решению это домашний **город** (грузы домой — с отметкой 🏠 первыми).
- Грузы с допусками, которых нет у водителя (ADR, TIR, разрешение РФ), не скрываются: у `Cargo` вообще нет поля «нужные допуски».
- Не учитываются кузов и тоннаж водителя.
- Вкладки водителя: Лента · Сделки · Профиль. По макету — **Главная · Грузы · Чаты · Профиль**; главной с анонсом (макет 01) и вкладки «Чаты» нет.

## Что сделать

### Бэкенд — подбор на сервере
1. `Cargo.requiredPermitIds` (допуски, нужные для груза) — логист отмечает при публикации.
2. `GET /cargos/feed` для водителя (пагинация, 20 на страницу):
   - **скрыть**: грузы, требующие допусков, которых нет у водителя; кузов не совпадает с кузовом машины; вес груза больше грузоподъёмности;
   - **секции**: 🏠 «Домой» (город назначения = домашний город водителя или тот же регион) → «Ваши страны» (`tripCountryIds` активного анонса, иначе страны профиля; `anyCountry` — все) → «Другие» (серым, внизу);
   - внутри секции: дата готовности ↑, затем свежесть публикации;
   - в ответе — секция каждого груза и пересчёт цены в KZT (и в валюту, выбранную водителем, по умолчанию KZT) по курсу НБ РК (задача 018).
3. Фильтры ленты (вкладка «Грузы»): страна, дата готовности, «только с ценой выше …».

### Flutter
4. Вкладки водителя: **Главная · Грузы · Чаты · Профиль** (макет 01).
5. **Главная**: карточка анонса (из 015) + «Подходящие грузы · N» — первые 5 из ленты с секциями; «Все» → вкладка «Грузы».
6. **Карточка груза** (`CargoCard`, макет 01): 🏠 «Домой» в янтарной рамке; маршрут крупно; кузов · вес · объём; компания + ★; цена крупно + «≈ … ₸».
7. **Вкладка «Чаты»**: список чатов водителя (задача 017), бейдж непрочитанных.
8. Офлайн: последняя загруженная лента показывается без сети с пометкой «обновлено N мин назад».

## Готово, когда
- Водитель без ADR не видит грузы, требующие ADR (тест API).
- Водитель из Шымкента видит груз в Шымкент в секции «Домой», а груз в Алматы — в «Ваших странах».
- Лента открывается одной страницей ≤ 20 грузов, следующая — при прокрутке.
- Главная и вкладки совпадают с макетом 01.
