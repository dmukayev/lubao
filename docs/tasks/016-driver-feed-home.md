# 016 — Лента грузов водителя и главная по макету 01

Статус: не начато · после 015

## Проблема (ревью 2026-10-04)
- `GET /cargos` отдаёт **все** опубликованные грузы, сортировка — на клиенте (`sortCargoFeed`). С ростом числа грузов это медленно и тяжело для мобильного интернета на границе.
- «Близко к дому» считается по **стране**: для казахстанского водителя все грузы в Казахстан — «домой». Нужно — по **области** домашнего города **или ближе 200 км в той же стране** (решения 2026-10-04 и 2026-10-05).
- Грузы с допусками, которых нет у водителя (ADR, TIR, разрешение РФ), не скрываются: у `Cargo` вообще нет поля «нужные допуски».
- Не учитываются кузов и тоннаж водителя.
- Вкладки водителя: Лента · Сделки · Профиль. По макету — **Главная · Грузы · Чаты · Профиль**; главной с анонсом (макет 01) и вкладки «Чаты» нет.

## Что сделать

### Бэкенд — подбор на сервере
1. `Cargo.requiredPermitIds` (допуски, нужные для груза) — логист отмечает при публикации.
2. `GET /cargos/feed` для водителя (пагинация, 20 на страницу):
   - **скрыть**: грузы, требующие допусков, которых нет у водителя; кузов не совпадает с кузовом машины; вес груза больше грузоподъёмности;
   - **секции**: 🏠 «Близко к дому» (город назначения **в той же области**, что и домашний город водителя — `City.regionId`, **или в той же стране и ближе `homeRadiusKm` = 200 км** по прямой (haversine по `City.lat/lng`, только если координаты есть у обоих городов); если у груза указана только страна — не «Близко к дому»; внутри секции ближние выше, затем дата готовности) → «Ваши страны» (`tripCountryIds` активного анонса, иначе страны профиля; `anyCountry` — все) → «Другие» (серым, внизу);
   - внутри секции: дата готовности ↑, затем свежесть публикации;
   - в ответе — секция каждого груза и пересчёт цены в KZT (и в валюту, выбранную водителем, по умолчанию KZT) по курсу НБ РК (задача 018).
2а. Координаты городов: заполнить `lat/lng` всем городам из `seed.ts` (сейчас пусто) — миграция данных, не только сид, чтобы существующие базы тоже получили координаты. Новый город при модерации (021) — админ указывает координаты (необязательно; без них работает только правило области). `app_settings.homeRadiusKm = 200` + поле в админке.
3. Фильтры ленты (вкладка «Грузы»): страна, дата готовности, «только с ценой выше …».

### Flutter
4. Вкладки водителя: **Главная · Грузы · Чаты · Профиль** (макет 01).
5. **Главная**: карточка анонса (из 015) + «Подходящие грузы · N» — первые 5 из ленты с секциями; «Все» → вкладка «Грузы».
6. **Карточка груза** (`CargoCard`, макет 01): 🏠 «Близко к дому» в янтарной рамке; маршрут крупно; кузов · вес · объём; компания + ★; цена крупно + «≈ … ₸».
7. **Вкладка «Чаты»**: список чатов водителя (задача 017), бейдж непрочитанных.
8. Офлайн: последняя загруженная лента показывается без сети с пометкой «обновлено N мин назад».

## Готово, когда
- Водитель без ADR не видит грузы, требующие ADR (тест API).
- Водитель из Жаркента видит грузы в Жаркент и Талдыкорган (та же область) в секции «Близко к дому», а груз в Алматы (~300 км, другой регион) — в «Ваших странах».
- Водитель из Алматы видит «Близко к дому» грузы в Каскелен и Талгар (другая область, < 200 км).
- Водитель из Шымкента не видит «Близко к дому» груз в Ташкент (другая страна, хотя ~120 км).
- Город без координат: «Близко к дому» работает по области, без ошибок.
- Лента открывается одной страницей ≤ 20 грузов, следующая — при прокрутке.
- Главная и вкладки совпадают с макетом 01.


> 2026-10-05: секция называется **«Близко к дому»** (kk «Үйге жақын», zh «离家近», en «Near home»), не «Домой». ARB уже обновлён.
