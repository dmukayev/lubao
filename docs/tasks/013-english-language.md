# 013 — Английский язык (четвёртый)

Статус: не начато · после 006, до 009/012 (чтобы новые экраны сразу делались на 4 языках)

Решение — `docs/decisions.md` (2026-10-04, «Английский — четвёртый язык»).

## Что сделать

### Бэкенд
1. Prisma: `enum Locale { kk ru zh en }` + миграция.
2. Справочники (`Json {kk, ru, zh}`) → `{kk, ru, zh, en}`. Тип `I18n` в `seed.ts` и DTO — добавить `en`; заполнить английские названия всех справочников (страны, регионы, города, терминалы, кузова, допуски, шаблоны сообщений). Существующие записи в БД — миграцией данных.
3. Если в справочнике нет перевода на нужный язык → отдавать `ru`.
4. Валидация `users.language`: kk / ru / zh / en.
5. Тексты push/WeCom-шаблонов (задача 011) — сразу на 4 языках.

### Flutter
6. `packages/lubao_core/lib/l10n/app_en.arb` — все ключи (перевести, затем вычитать: логистические термины — TIR, CMR, reefer, curtainsider/tilt и т. п.).
7. Язык по умолчанию при первом запуске:
   - телефон на kk / ru / zh → этот язык;
   - телефон на en → en;
   - любой другой → ru.
8. Все переключатели языка — 4 варианта: **Қазақша · Русский · 中文 · English** (экран первого запуска, плашка на входе, строка в профиле водителя, боковое меню логиста `中文 / RU / KZ / EN / EN`, «Мой профиль» логиста).
9. Подпись строки языка в профиле водителя: «Язык · Тіл · 语言 · Language».

## Готово, когда
- Телефон на английском → приложение открывается на английском; на немецком → на русском.
- В интерфейсе на английском нет строк на других языках (включая справочники).
- `flutter gen-l10n` без предупреждений о недостающих ключах для en.
