## 🔴
1. **«Создать водителя» раскрывает, кто владелец номера** (`company-drivers.service.ts:145-176,72-73`).
   - Сейчас ответ различает `CREATED` и `INVITED_EXISTING` («Водитель уже в Lubao»), а для неподтверждённой строки отдаётся `driverId`, по которому `GET /drivers/:id/card` показывает ФИО и фото. Любая компания проверяет до 50 номеров в сутки.
   - Исправить:
     - на любой номер — одинаковый ответ `{status:'INVITED', url}`;
     - до «Принять» в списке только `rowId`, имя, введённое компанией, и «ждёт входа» — без `driverId`;
     - карточка водителя по неподтверждённой строке не открывается.
2. **Push с адресом вкладки поверх вложенного экрана** (`push_service.dart:201`). `/arrival`, `/profile`, `/verification`, `/company/drivers` через `router.push`, когда открыт чат или сделка, дают вторую копию оболочки вкладок («Duplicate GlobalKey») или ленту внутри чужой вкладки.
   - Адреса вкладок — через `go()`; `push` — только для вложенных экранов (`/chat`, `/deal`, `/driver/cargo`, `/company/cargos/:id/responses`, `/driver/history`).
   - e2e: push `/arrival`, когда открыт чат.

## 🟠
3. **Цена поменялась в момент выбора** (`responses.service.ts:580-591,487`; чат `chat_screen.dart:653`).
   - Клиент передаёт `expectedPrice`; сервер сверяет под замком груза: расхождение → 409 `PRICE_CHANGED` «Водитель изменил цену».
   - `updateOffer` — под `lockCargo` и только при статусе PENDING.
   - В чате кнопка «Выбрать за …» с ценой водителя.
4. **Груз на несколько машин:**
   - а) «Нашёл в Lubao» при `trucksNeeded > 1` оставляет груз в ленте и шлёт «груз снят» (`cargos.service.ts:1003`). Уменьшать `trucksNeeded` до числа взятых мест и снимать с поиска;
   - б) изменение `trucksNeeded` — в одной транзакции под `lockCargo` с пересчётом статуса; `claimPlace` дополнительно проверяет, что груз в поиске (`cargos.service.ts:906-946`);
   - в) архив по сроку (`jobs.service.ts:178-193`) и «доставлено» в админке (`admin.service.ts:1003`) — только если нет незавершённых сделок, иначе груз уходит в «В работе»;
   - г) при наборе мест через правку `trucksNeeded` — причина «ушёл другому», а не «груз снят».
5. **Смена валюты груза** при откликах с ценой или живых сделках — запретить (409), иначе $9 500 превращается в ₸9 500 (`cargos.service.ts:926`).
