# 050 — Вход через бот Telegram и «обратный» вход через WhatsApp

Статус: не начато · после 049. Оценка: 3–4 часа.
Решение: `docs/decisions.md` → «Вход без кода: бот Telegram и обратный WhatsApp» (2026-10-08). Дополняет каналы кода (042 п.3), не заменяет: SMS остаётся запасным.

## Что сделать
1. **Telegram-бот** (env `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`; без них кнопка скрыта):
   - экран входа водителя — кнопка «Войти через Telegram» → сервер создаёт `loginNonce` (TTL 5 мин) → приложение открывает `https://t.me/<bot>?start=<nonce>`;
   - бот (webhook `POST /telegram/webhook`, секрет в заголовке `X-Telegram-Bot-Api-Secret-Token`) на `/start <nonce>` отвечает на языке пользователя Telegram и показывает одну кнопку `request_contact` «Поделиться номером»;
   - на `contact`: принимать **только если `contact.user_id == from.id`** (свой номер, не пересланный чужой) → нормализовать номер → привязать к nonce → приложение (ждёт по WebSocket или опрашивает `GET /auth/telegram/:nonce` раз в 2 с) получает токены — вход или регистрация по номеру, как после SMS-кода; бот пишет «Готово, вернитесь в приложение» с кнопкой-ссылкой `lubao://` / App Link;
   - `telegramUserId` сохранять у пользователя (повторный вход — одной кнопкой «Старт», без повторного контакта).
2. **WhatsApp «обратный вход»** (нужен WhatsApp Cloud API: `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_ID`, публичный номер `WHATSAPP_PUBLIC_NUMBER`; без них кнопка скрыта):
   - кнопка «Войти через WhatsApp» → `loginNonce` (4–6 цифр, TTL 5 мин) → открыть `https://wa.me/<номер>?text=Lubao%20вход%20<nonce>`;
   - webhook Meta `POST /whatsapp/webhook` (проверка подписи `X-Hub-Signature-256`, verify-token для подписки): входящее сообщение с `<nonce>` → номер отправителя `from` → вход/регистрация, ответ в WhatsApp «Готово, вернитесь в приложение»; входящие пользователь→бизнес бесплатны, шаблон не нужен;
   - неофициальные библиотеки к обычному WhatsApp — **не использовать** (бан номера).
3. **Админка → «Каналы входа»** (расширение 042 п.3): Telegram-бот, WhatsApp обратный, WhatsApp-код, Telegram Gateway, SMS — вкл/выкл и порядок кнопок на экране входа; без ключей — серым.
4. Защита: лимит nonce на устройство/IP (как у SMS), nonce одноразовый (атомарно), номер из Telegram/WhatsApp проходит те же проверки, что после SMS (чёрный список по телефону — 039 п.2).
5. ARB 4 языка (кнопки, ответы бота — на языке из `language_code` Telegram / языке приложения). Тесты: чужой контакт отклоняется, повтор nonce → 409, истёкший nonce, подпись webhook; e2e — мок webhook'ов: «Войти через Telegram» → контакт → вход.

## Готово, когда
- С токеном бота водитель входит в 3 нажатия без кода: «Войти через Telegram» → «Старт» → «Поделиться номером».
- С Cloud API водитель входит, отправив предзаполненное сообщение в WhatsApp.
- Каналы включаются и упорядочиваются в админке без релиза.
