# 071 — Логист: нажатие на свой груз → полная информация с фото, ниже отклики

Статус: не начато.
Откуда: владелец 2026-10-13 — «когда логист нажимает карточку груза, там должна быть полная информация про груз с фото».
Оценка: 3–4 часа.

## Сейчас
Нажатие на груз в «Грузы» открывает `/company/cargos/:id/responses`. Сверху маленькая сводка `_CargoSummaryCard` (номер, маршрут, дата, цена), ниже отклики. Фото, описания, условий оплаты и параметров груза нет. У водителя полная карточка уже есть (`cargo_detail_screen.dart`).

## Что сделать
1. **Тот же экран, сверху — полная карточка груза** вместо `_CargoSummaryCard`. Блоки — общие с карточкой водителя (вынести в общий виджет, не копировать). Сверху вниз:
   - **фото груза** — лента миниатюр; нажатие → на весь экран с листанием, закрытие ✕ или свайпом вниз. Фото нет — блока нет;
   - маршрут с флагами (город погрузки → страна/город выгрузки), км;
   - номер груза, дата и время публикации, статус («Истекает завтра», «В работе» …);
   - категория, кузов (и дополнительные кузова), вес, объём, параметры по профилю кузова (`specs`), «можно догрузом»;
   - дата погрузки;
   - правый столбец цены как в 065: цена → «≈ … ₸» → ₸/км → «через N дн. · нал.»; зелёная плашка аванса;
   - «нужно 5 машин» / «нужно 2 · осталось 1»;
   - описание — целиком, без обрезки;
   - кто опубликовал (логист компании) — если груз не свой.
2. **Действия** — в шапке или под карточкой, маленькими серыми кнопками:
   - «Изменить», «Поделиться», «Повторить», «Снять с публикации»;
   - в «Архиве» — только «Повторить».
3. **Ниже — «Отклики: N · M новых»** и список, как сейчас. Если откликов много, полная карточка не должна их прятать. Достаточно, чтобы после неё было видно начало списка откликов при прокрутке; сворачивать карточку не нужно.
4. **Чат → закреплённая карточка груза** ведёт сюда же.
5. **Узкий экран** (360 dp × 1,3, SE с крупным шрифтом): ничего не обрезано, кроме маршрута многоточием.
6. ARB — 4 языка для новых строк.
7. **e2e:** в сценарии логиста нажатие на груз → видно фото, описание, условия оплаты и «Отклики». Нажатие на фото открывает его на весь экран.

## Готово, когда
- Логист видит свой груз целиком, с фото, на том же экране, что и отклики.
- Снимки на Android 360 и iPhone SE (крупный шрифт) — в `evidence/071/`.
- Шаги логиста в e2e зелёные на обеих платформах (полный прогон — вместе со следующей большой задачей).
