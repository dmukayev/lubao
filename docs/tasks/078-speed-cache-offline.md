# 078 — Скорость: чат мгновенно, кэш, режим без связи

Статус: **готово** (2026-10-14).
- п.1 ✅ Чат по «Написать»:
  - открывается сразу (`/chat/open`, `ChatOpeningScreen`) с именем собеседника в шапке и активным полем ввода; `findOrCreate` — в фоне, затем на том же экране обычный чат с закреплённой карточкой;
  - написанное до ответа — очередью, набранный текст не теряется;
  - связь «водитель/груз → чат» запоминается на телефоне — повторное нажатие без запроса (e2e проверяет отсутствие `POST /chats` по журналу запросов);
  - подключено везде: карточка груза у водителя, карточка водителя (было без индикатора и защиты от двойного нажатия), отклики, сделка, «Кто свободен».
- п.2 ✅ Кэш на телефоне — файлы в `Application Support` (`DataCacheStore`, без новых нативных пакетов), отдельно на каждого пользователя.
  - **Как работает:**
    - `ApiClient` сохраняет удачные GET по списку адресов (`CachePolicy`);
    - экраны сначала показывают сохранённое (`cacheFirst`), потом свежее;
    - после изменения (POST/PATCH) в этом запуске сохранённое показывается, только если уже обновлено, — старое не мелькает.
  - **Что сохраняется:**
    - справочники (неделя);
    - чаты и последние 50 сообщений (с переводами — переводы хранит и не повторяет сервер);
    - карточки водителей (сутки);
    - свой профиль, машины, документы, статус проверки;
    - «Мои рейсы», сделки, грузы (у компании — первая страница вкладки);
    - лента — до 6 ч, старше часа — «обновляется…».
  - **Фото:** диск 7 дней (было: только лимит 400 файлов); без связи — и старше.
  - **Черновики:** форма груза — «Продолжить черновик?» / «Начать заново»; анонс — выбор восстанавливается без вопроса (шторка короткая).
  - **Не сохраняются чужие телефоны:**
    - адреса выдачи номера не входят в список;
    - поля `phone`/`contactPhone` вырезаются перед записью;
    - документы других людей не сохраняются.

    Исключение по решению 2026-10-14 — телефон логиста по текущей сделке, если водитель уже открыл его по нажатию: доступен без связи, пока сделка идёт.
  - **Выход и удаление аккаунта** — всё стирается.
  - **Не сделано:** дельта сообщений и версия справочников (ETag) — у сервера нет параметров «после» и версии. Чат и справочники пока перезапрашиваются целиком, но в фоне, поверх сохранённого.
- п.3 ✅ Без связи:
  - «Мои рейсы», карточка сделки, чаты (чтение) — из сохранённого;
  - сообщения — очередью на телефоне с пометкой «ожидает отправки», уходят сами (опрос, переподключение, возврат связи);
  - сверху тонкая полоса «Нет связи — показаны сохранённые данные». Полоса не пересоздаёт экраны.
- п.4 ✅ Запросы:
  - «Кто свободен» — грузы компании для города по умолчанию теперь из сохранённого, без ожидания сети перед списком;
  - N+1 нет (по водителю — только аватар, на диске по версии);
  - вкладки по-прежнему держат данные (060 не сломан: провайдеры остаются подписанными оболочками).
  - Найдено и исправлено: смена фильтра во время загрузки ленты (assert Riverpod после кэша).
- Заодно: высокие шторки (анонс, машина, город, выбор груза в чате, «Кто свободен», приглашение) — `useSafeArea`. На iPhone 17 Pro заголовок «Буду на точке» уходил под Dynamic Island (снимок владельца).
- п.5 ✅ e2e:
  - `driver_deal`:
    - «Написать» → через 300 мс экран чата с полем ввода; повторно — без `POST /chats`;
    - без связи (`ApiClient.simulateOffline`, только в отладочной сборке e2e) — полоса, «Мои рейсы», сделка и чат открываются, сообщение «ожидает отправки»;
    - связь вернулась — сообщение ушло, полоса пропала;
  - `logist_drivers` — черновик груза: «Продолжить черновик?» → цена на месте; «Начать заново»;
  - `error_messages` — «Нет интернета» проверяется без сохранённого (с сохранённым ошибки нет — показывается лента);
  - e2e перед сценарием стирает сохранённое.

  Юнит: core 90, приложение 87, админка 25.

## 1. Чат открывается мгновенно
- «Написать» (карточка груза у водителя, карточка водителя у логиста, отклики, сделка, «Кто свободен») → экран чата открывается **сразу** с шапкой и закреплённой карточкой; `findOrCreate` идёт в фоне. Поле ввода активно; отправленное до ответа сервера встаёт в очередь и уходит, когда тред получен.
- Связь «водитель → тред», «груз → тред» запоминается на телефоне: повторное нажатие — без запроса.
- Где мгновенно нельзя — индикатор на кнопке и защита от двойного нажатия (сейчас в `driver_card_screen._chat` индикатора нет).

## 2. Кэш на телефоне (локальная БД, не только память)
- **Справочники** (точки, страны, города, кузова, категории, товары, главы HS, курсы, шаблоны): на диске, версия/ETag с сервера; при запуске — из кэша, обновление в фоне.
- **Чаты:** список и последние 50 сообщений каждого треда; при открытии — из кэша, затем дельта с сервера.
- **Карточки** водителей и компаний, которые открывали, — 24 ч.
- **Фото** (аватары, кузова, грузы, машины) — дисковый кэш 7 дней; не перезагружать уже показанные.
- **Свой профиль, машины, документы, статус проверки** — при открытии из кэша, обновление в фоне.
- **«Мои рейсы» и сделки** — список и карточки.
- **Черновики** формы груза и анонса — восстановить после закрытия/падения («Продолжить черновик?»).
- **Переводы сообщений** — не переводить повторно.
- **Лента грузов** — как в 060, с пометкой «обновляется», если кэшу больше часа; старше 6 ч — не показывать без обновления.
- **Не кэшировать:** чужие телефоны (выдаются по нажатию и учитываются), документы других людей.
- Выход из аккаунта / смена пользователя — кэш очищается.

## 3. Режим без связи для водителя
- Без интернета открываются: «Мои рейсы», карточка текущей сделки (город, дата, телефон логиста — если был открыт по нажатию ранее и ещё в сделке), чаты (чтение).
- Сообщения без связи — в очередь, отправка при появлении сети, пометка «ожидает отправки».
- Сверху тонкая полоса «Нет связи — показаны сохранённые данные».

## 4. Не потяжелели ли экраны после 071/075
- Посмотреть число запросов при открытии «Грузы», ленты, карточки груза, «Кто свободен»: лишние — убрать или объединить; списки — без N+1 (приглашения, товары, курсы — одним запросом).
- Переключение вкладок — без перезагрузки (проверить, что 060 не сломано новыми экранами).

## 5. Проверка
- e2e: «Написать» открывает чат без ожидания; повторное открытие — без запроса (счётчик запросов в e2e-режиме); выключить сеть → «Мои рейсы» и чат читаются, сообщение ставится в очередь и уходит после включения.
- Снимки: полоса «Нет связи», черновик «Продолжить?».
- Замеров скорости не делать (владелец); `scripts/perf.sh` не запускать.
