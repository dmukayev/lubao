# 040 — Точка → город: анонс «свободен в городе», город погрузки в грузе, догруз

Статус: ✅ готово — итог внизу; `scripts/e2e.sh` зелёный на iPhone 17, iPhone 16e и в Chrome (1280 и 390) (2026-10-07) · после 041. Оценка: 2–3 дня.
Решение: `docs/decisions.md` → «Точка → город» (2026-10-06). Первый пилот — внутри Казахстана, Хоргос — один из городов. **Ничего китайского не удалять.**

## Что сделать

### Справочник
1. `points` остаются как «города/точки погрузки»: добавить `cityId` (связь с `cities`), `kind` (`CITY` | `TERMINAL`), `geofence` (lat/lng/radius, только для TERMINAL — Хоргос). Сид: областные центры РК + Хоргос (TERMINAL). Админка: CRUD с выбором города из справочника.
2. Экран выбора города (общий виджет в `lubao_core`): поиск по 4 языкам, недавние, «рядом со мной» по геолокации (если разрешена). Используется в анонсе, в грузе, в профиле («домашний город» уже есть — переиспользовать).

### Водитель
3. Анонс: вместо «точка» — **город** + дата + срок ожидания + направления («куда готов ехать» — страны/области, как сейчас). Несколько анонсов подряд разрешены (разные города/даты), не более одного ON_SITE одновременно.
4. Свежесть (правило из decisions.md, заменяет 014): PLANNED — молчим до дня приезда; в день приезда push «Доехали? Нажмите „Я на месте“», к концу дня не нажал → EXPIRED; ON_SITE — «Ещё ищете груз?» каждые 12 ч (push с кнопками «Да / Уехал»), без ответа 12 ч → EXPIRED; сделка `CONFIRMED_BY_DRIVER` → анонс COMPLETED автоматически. Геозона — только для TERMINAL (авто «уехал» при выходе из радиуса, если геолокация разрешена). Планировщик — из 042 (если 042 ещё нет — `@nestjs/schedule` поставить здесь).
5. Лента: грузы с городом погрузки = текущий город анонса → та же область / ≤200 км → остальные (правило «близко к дому» применить к городу анонса, фолбэк — домашний город). Сортировка и отсев **на сервере**, пагинация (из 016 — п.1–3; остальное 016 остаётся).
6. **Догруз возвращается:** у груза `allowPartial` («можно догрузом») — переключатель у логиста; в ленте бейдж «Догруз»; у водителя с активной сделкой подсказка «Помещается к текущему: 8 т + 10 т из 20 т» (расчёт уже есть в `assertVehicleNotFull` — переиспользовать, не дублировать).

### Логист
7. Груз: **город погрузки — обязательное поле** (выбор из справочника), в карточке и ленте — крупно. Было: первая активная точка без выбора.
8. «Кто будет на точке» → «**Кто свободен в <город>**»: сверху выбор города (по умолчанию — город последнего груза компании), остальное — экран 036 без изменений. Фильтр «едет в <направление>».

### Админка
9. Справочник точек с `kind`/геозоной; на дашборде — разрез по городам (анонсы/грузы/сделки).

### Качество
10. Миграция без потери данных: существующие анонсы/грузы получают `pointId` Хоргоса (он уже есть), `kind=TERMINAL`, геозона из текущих настроек. Проверить на базе с демо-данными.
11. ARB 4 языка; **ни одного «Хоргос» в текстах**; тесты: сортировка ленты по городу/области/200 км, угасание анонса по правилу п.4 (все 4 ветки), догруз в ленте; шаги 034: анонс в Алматы → груз из Алматы виден первым; «Кто свободен» с выбором города.

## Готово, когда
- Водитель объявляет «свободен в Алматы в чт», логист с грузом из Алматы видит его в «Кто свободен в Алматы», водитель видит этот груз первым.
- Анонс гаснет по правилу (день приезда / 12 ч / сделка) — тесты.
- Хоргос работает как раньше (TERMINAL, геозона), демо-данные не потеряны.
- Груз без города опубликовать нельзя.
