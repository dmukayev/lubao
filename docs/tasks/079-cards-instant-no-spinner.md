# 079 — Карточки открываются мгновенно из уже загруженного; без крутилки

Статус: не начато.
Решение: `docs/decisions.md` → «2026-10-16 · Карточки открываются из того, что уже есть». Владелец 2026-10-16: «в карточку груза заходишь — чуть тормозит, подгружается»; «крутилку не надо, пусть появляется как будет».
Оценка: 4–6 часов. Проверка — затронутые сценарии e2e на iPhone SE и Android 360 + снимки; полный прогон не нужен.

## 1. Карточка груза у водителя (`cargo_detail_screen.dart`)
- Переход из ленты, «Моих рейсов», сделки, чата, избранного, push передаёт **объект `Cargo`** (через `extra` роутера), а не только id. Экран рисуется из него сразу: маршрут, цена и столбец 065, кузов, вес, товар, дата, компания и плашка «Проверена», миниатюры фото.
- `cargoByIdProvider` остаётся, но работает в фоне: пришёл ответ — дорисовать описание целиком, все фото, актуальный статус; расхождений не «моргать», обновлять на месте.
- Открытие по ссылке/push без объекта — из кэша 078, если есть; иначе — как сейчас, но без крутилки на весь экран.
- **Крутилок нет.** `LoadingView` на весь экран убрать. Блоки «ваш отклик», «догруз», «похожие» появляются, когда пришли; до этого на их месте ничего (не скелетон, не индикатор). Кнопки «Откликнуться / Позвонить / Написать» активны сразу (отклик — с защитой от двойного нажатия).
- **Один запрос вместо трёх:** `GET /cargos/:id` отдаёт груз + мой отклик по нему (`myResponse`) + подсказку догруза (`partialHint`). Отдельные `myCargoResponseProvider` и `partialHintProvider` читают из него.

## 2. Карточка груза у логиста (`/company/cargos/:id`, 071)
- То же: из строки списка «Грузы» объект груза в `extra`; отклики и приглашения — вторым запросом в фоне, список появляется, когда пришёл. Крутилки нет.

## 3. Карточка водителя (`showDriverInfoSheet`, 067)
- Шторка открывается с тем, что есть в строке списка (имя, аватар, «Проверен», рейтинг, машина, статус); полная карточка (фото машины, отзывы, допуски) дорисовывается. Крутилки нет.

## 4. Фото
- Миниатюра из ленты — из дискового кэша 078; полное фото подгружается при открытии на весь экран.

## 5. Проверка
- e2e: открыть груз из ленты → маршрут и цена видны **в том же кадре** (без ожидания сети: в e2e-режиме сервер отвечает с задержкой 2 с, карточка всё равно сразу показана); то же у логиста и в шторке водителя.
- `grep -rn "LoadingView" apps/lubao_app/lib/features/driver/feed/cargo_detail_screen.dart` — пусто.
- Снимки `evidence/079/`: карточка через 100 мс после нажатия (Android 360, iPhone SE).
