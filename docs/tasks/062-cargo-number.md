# 062 — Короткий номер груза и сделки

Статус: **готово** (2026-10-11).
- п.1: `cargos.number` — 6 цифр, случайный свободный номер выдаёт база (`lubao_cargo_number()` по умолчанию), уникальный индекс; `deals.seq` — номер машины по грузу ставит триггер при вставке (сделки создаются под замком груза), уникально `(cargoId, seq)`. Миграция заполняет существующие грузы (разные номера из перемешанного пула) и сделки; проверена на dev-базе с демо-данными и на чистой (e2e).
- п.2: `number` в ответах груза (все пути через `toDto`), `cargoNumber` + `seq` в сделке, `seq` у сделки в списке грузов логиста.
- п.3: «№ 482 915» — карточка груза у водителя, список грузов и отклики у логиста (в работе — номер сделки), закреплённая карточка чата; «Сделка № 482 915-1» — заголовок сделки; нажатие на номер копирует его (без пробелов).
- п.4: страница «Поделиться» — номер груза на языке устройства («№», «编号», «No.»).
- п.5: push о сделке («Вас выбрали», смена статуса обеим сторонам) — «· № 482 915-1» в заголовке.
- п.6: админка — поиск по номеру груза и сделки («482 915», «482915», «№ 482 915-1»; кусок id — как раньше), номер в списках, карточках и подсказках общего поиска.
- п.7: бэкенд — формат, разбор запроса, поиск, заголовок push (1 179 тестов); e2e — номер в карточке груза и копирование (`driver_flow`), «Сделка № …-1» (`trade_offers`), API-смоук админки — номер в списках, поиск по номеру груза и сделки, номер на странице «Поделиться». Полный `scripts/e2e.sh` — все сценарии зелёные на iPhone SE и Android 360 + Chrome (`evidence/062/e2e-full-run.md`).
Решение: `docs/decisions.md` → «Номер груза и сделки» (2026-10-11). Откуда: владелец 2026-10-11 — номер, который удобно назвать по телефону.

## Что сделать
1. **База:** `cargos.number` — 6 цифр, уникальный, случайный (повтор при совпадении); `deals.seq` — номер машины по грузу (1, 2, …), уникальный в паре с грузом. Миграция заполняет существующие грузы и сделки.
2. **API:** номер в ответах груза, ленты, сделки, чата.
3. **Приложение:** «№ 482 915» в карточке груза (водитель и логист), в списке грузов логиста, в закреплённой карточке чата; «№ 482 915-1» в сделке.
4. **Страница «Поделиться»** — номер груза.
5. **Push о сделке** — номер сделки в тексте.
6. **Админка:** поиск по номеру груза и сделки (с пробелами и без, «482915-1»), номер в списках и карточках.
7. **Тесты:** бэкенд — выдача номера и повтор при совпадении, номер сделки, поиск; e2e — номер в карточке груза и сделке, поиск в админке.

## Готово, когда
- У каждого груза и сделки есть короткий номер, он виден везде, где обсуждают груз, и по нему находится груз в админке.
- `scripts/e2e.sh` зелёный на iPhone SE и Android 360 dp + Chrome.
