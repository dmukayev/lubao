# Задачи

Каждая задача — отдельный файл `NNN-название.md`: цель, что сделать, критерии «Готово», статус.
Выполнять по порядку номеров, если в задаче не сказано иначе.

Как запускать в Claude Code:
> git pull и выполни docs/tasks/001-backend-skeleton.md

По завершении поменяй строку `Статус:` в файле задачи на `готово` и коротко опиши, что сделано.
