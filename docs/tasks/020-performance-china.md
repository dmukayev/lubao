# 020 — Скорость и работа из Китая

Статус: не начато · **часть А — сразу после 006** (без неё пилот с китайскими логистами невозможен), части Б–Г — до пилота

Решение — `docs/decisions.md` (2026-10-04, «Скорость и работа из Китая»).

## Цели
| Что | Цель |
|---|---|
| Холодный запуск приложения водителя (Android среднего класса) | ≤ 2 с до первого экрана |
| Лента грузов на 4G | ≤ 1 с; без сети — последняя сохранённая |
| Веб-кабинет логиста из Китая, первое открытие | ≤ 5 с |
| Повторное открытие веб-кабинета | ≤ 1 с |
| API, p95 | ≤ 300 мс (без учёта сети) |

## А. Flutter Web без Google (блокер для Китая)
По умолчанию Flutter Web тянет с серверов Google, заблокированных в Китае:
- движок CanvasKit с `www.gstatic.com` → страница не открывается или висит;
- fallback-шрифты для недостающих глифов (в т. ч. CJK) с `fonts.gstatic.com` → иероглифы квадратиками.

1. Хостить CanvasKit/skwasm у себя: в `web/index.html` / `flutter_bootstrap.js` задать `canvasKitBaseUrl: "/canvaskit/"` (файлы из `build/web/canvaskit` раздаёт наш nginx). Проверить, что в собранном `build/web` нет ссылок на `gstatic.com` / `googleapis.com` (`grep -r` в CI — сборка падает, если нашлись).
2. Шрифты: Onest (уже в assets) + **Noto Sans SC, урезанный до ~3500 частотных иероглифов + все символы из ARB `app_zh.arb`** (subset через `pyftsubset`, woff2) — вшить в assets, указать как fallback в теме. Отключить загрузку fallback-шрифтов из сети.
3. Иконки — только `lucide_icons` (локальные), `cupertino_icons` и Material Icons из сети не тянуть.
4. Сжатие: nginx — brotli/gzip для `.js`, `.wasm`, `.json`, шрифтов; долгий кэш (`immutable`) для хэшированных файлов, `index.html` и `flutter_bootstrap.js` — без кэша.
5. Экран загрузки в `index.html` (логотип 路宝 + «Загрузка…» на 4 языках), пока грузится движок, — чтобы пользователь не видел белый экран.
6. Сравнить рендереры (CanvasKit vs skwasm) по размеру и скорости первого открытия, выбрать и обосновать.

## Б. Бэкенд
7. **N+1 запросы** — убрать:
   - `arrivals.service.ts → listForCompany`: на каждый анонс отдельно `vehicle.findFirst` и `driverDirection.findMany` → один запрос с `include` / батч-загрузка;
   - `cargos.service.ts → toDto`: подсчёт сделок компании на каждый груз → агрегировать одним запросом или хранить счётчик в `Company`;
   - пройтись по остальным сервисам тем же взглядом (Prisma query log в dev, предупреждение при > 10 запросов на один HTTP-запрос).
8. Индексы под реальные фильтры: анонсы (`pointId, status, plannedAt`), грузы (`status, readyDate`, `destinationCountryId`), сообщения (`chatId, createdAt`), `contact_events` (`cargoId, createdAt`). Проверить `EXPLAIN` на данных из сида × 100.
9. Пагинация везде, где список может расти: лента грузов (016), «Кто будет» (015), мои грузы, сделки, чаты, сообщения (курсор, по 20–50).
10. Сжатие ответов API (gzip/brotli в nginx), отдавать только нужные поля (без вложенных объектов целиком).
11. Справочники: `GET /reference-data` с `ETag` + `Cache-Control`; клиент хранит локально и запрашивает только при изменении версии.

## В. Фото и клиент
12. При загрузке фото — уменьшенные копии: `thumb` 320 px и `medium` 1280 px (WebP/JPEG), оригинал — только для админа (документы). Карточки и списки показывают `thumb`.
13. Клиент: кэш изображений, ленивые списки (`ListView.builder`), skeleton вместо спиннеров, офлайн-кэш ленты и анонса (последние данные + «обновлено N мин назад»).
14. Размер APK/IPA: `--split-per-abi`, tree-shaking иконок, без неиспользуемых пакетов. Цель — APK ≤ 25 МБ.

## Г. Измерение и проверка
15. Метрики API: время ответа по эндпоинтам (p50/p95), медленные запросы к БД (> 200 мс) — в лог и на страницу админки «Система».
16. Нагрузочный тест (k6): 500 одновременных пользователей (400 водителей, 100 логистов) — открыть ленту, «Кто будет», чат; p95 ≤ 300 мс, без ошибок. Сценарий и отчёт — в `docs/perf/`.
17. **Проверка из Китая (обязательно):** с VPS в материковом Китае (Alibaba Cloud / Tencent Cloud, Пекин или Урумчи) или через китайского логиста — открыть веб-кабинет, замерить первое открытие и задержку API до сервера в РК; результат — в `docs/perf/china-check.md`. Если задержка API > 500 мс или потери пакетов > 2 % — предложить вариант со статикой через узел в Гонконге (данные остаются в РК).

## Готово, когда
- В `build/web` нет обращений к доменам Google; веб-кабинет открывается из Китая ≤ 5 с, иероглифы отображаются.
- «Кто будет на Хоргосе» на 200 водителях — ≤ 5 запросов к БД.
- Нагрузочный тест проходит с p95 ≤ 300 мс.
- Цели из таблицы выше подтверждены замерами в `docs/perf/`.
