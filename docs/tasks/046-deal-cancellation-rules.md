## Что сделать
1. **Причины списком** для обеих ролей: enum `cancelReasonCode` — `VEHICLE_BREAKDOWN`, `CARGO_NOT_READY`, `OTHER_PARTY_UNRESPONSIVE`, `TERMS_CHANGED`, `TOOK_OTHER_CARGO` (есть), `OTHER` (+ обязательный текст). Миграция: старые текстовые причины → `OTHER` с текстом. Диалог отмены — чипы причин, текст только для «Другое».
2. **Категория отмены** — `cancelStage`: `BEFORE_CONFIRM` (SELECTED), `AFTER_CONFIRM` (CONFIRMED_BY_DRIVER), `AFTER_LOAD` (LOADED), `IN_TRANSIT`. Заполняется автоматически по статусу на момент отмены. `faultSide`: по коду причины — `SELF` / `OTHER_PARTY` / `NEUTRAL` (таблица в коде, правится без миграции).
3. **Статистика сторон:** `driverCancelStats` и `companyCancelStats` — всего / после загрузки / по своей вине; показывать в карточке водителя у логиста («отменил 1 из 15 · после загрузки 1») и в карточке компании у водителя (карточка груза, чат). В админке — те же цифры + список отмен с причинами.
4. **Рейтинг:** отмена после загрузки по своей вине снижает рейтинг сильнее (вес ×3 против ×1 после подтверждения; вес — настройка в `app_settings`); отмена из-за другой стороны — не снижает.
5. **Запрос на отмену после «В пути»:** статус сделки `CANCEL_REQUESTED` с инициатором, причиной и сроком 24 ч; вторая сторона — «Подтвердить отмену» (→ CANCELLED, `faultSide` по причине) или «Оспорить» (→ `DISPUTED`, строка в «Требует внимания» админа с обеими позициями; админ закрывает: отменить с указанием виновной стороны / вернуть в IN_TRANSIT). Без ответа 24 ч → отмена проходит, `faultSide = OTHER_PARTY` для молчавшего. Push и системные строки в чат на каждом шаге.
6. При отмене на стадии `AFTER_LOAD`/`IN_TRANSIT` — после диалога сразу предложение «Пожаловаться» с предзаполненной сделкой.
7. ARB 4 языка; тесты: категория по статусу, вес рейтинга, запрос/подтверждение/спор/таймаут; e2e: отмена после загрузки → у логиста в карточке водителя «после загрузки 1»; запрос отмены в пути → спор → админ закрывает.

## Готово, когда
- Отмена всегда с причиной из списка; у обеих сторон видна статистика отмен друг друга с категорией.
- После «В пути» одна сторона не может закрыть сделку без второй; спор попадает админу.
- Отмена после загрузки по своей вине заметно бьёт по рейтингу, из-за другой стороны — нет.
