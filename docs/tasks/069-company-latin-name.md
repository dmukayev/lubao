# 069 — Регистрация компании: латинское название, если название на китайском

Статус: не начато.
Откуда: владелец 2026-10-13 — «при регистрации вместо имени на русском сделай имя на латинице, если название компании на китайском».
Оценка: 2–3 часа.

## Сейчас
`company_register_screen.dart`: «Название компании» + «Название по-русски» (`nameRu`, копируется из первого поля, пока его не правили). Китайскому логисту писать по-русски трудно, а водитель иероглифы не прочтёт.

## Что сделать
1. **Форма регистрации и профиль компании:**
   - в названии есть иероглифы (CJK) → второе поле становится **«Название латиницей»** с примером «Horgos Ruida Trading» и подсказкой «Так вашу компанию увидят водители»; поле обязательное;
   - автозаполнение: пиньинь из китайского названия (локальная библиотека, без облака), логист может исправить;
   - название кириллицей или латиницей → второго поля нет;
   - разрешены латиница, цифры, пробел и `. , & - ( ) '`, длина 2–100.
2. **Данные:**
   - новая колонка `companies.nameLatin` (nullable);
   - `nameRu` больше не спрашиваем; существующие значения не трогаем;
   - миграция проверена на базе с демо-данными.
3. **Где показывается** (водителю — в ленте, карточке груза, чате, сделке, «Поделиться», push):
   - у компании с китайским названием — **латиницей**, оригинал мелко серым рядом там, где есть место (карточка груза, профиль компании);
   - у логиста и в китайском интерфейсе — оригинал;
   - нет `nameLatin` у старой компании → `nameRu`, если есть, иначе оригинал.
4. **Админка:**
   - в карточке компании видны оба названия, `nameLatin` можно править;
   - в «Требует внимания» — китайские компании без `nameLatin`.
5. ARB — 4 языка.
6. **e2e:** регистрация компании с названием «霍尔果斯瑞达贸易有限公司» → появилось поле латиницей с пиньинем → у водителя в ленте латинское название.

## Готово, когда
- Китайская компания при регистрации вводит латинское название, а водитель видит его везде.
- `scripts/e2e.sh` зелёный на iPhone SE и Android 360 (крупный шрифт) + Chrome.
