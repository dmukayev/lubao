# 054 — Фото профиля водителя

Статус: ✅ готово 2026-10-09 (см. «Статус по пунктам»). Оценка: 3–4 часа. Решение: `docs/decisions.md` → «Фото профиля водителя» (2026-10-09).

## Что сделать
1. **Модель.** Отдельное фото профиля: файл в приватном хранилище, ссылка у водителя (`avatarFileKey`, миграция). Селфи проверки и его доступ (044) не меняются.
2. **Предложение после проверки.** Когда селфи принято — один раз карточка в профиле:
   - текст: «Поставить это фото в профиль? Логисты будут видеть его»;
   - кнопки: «Да» (копия селфи → фото профиля) / «Сделать другое» (камера) / «Не сейчас»;
   - согласие записать в журнал.
3. **Профиль водителя.** Фото рядом с именем, нажатие — «Сменить фото» / «Убрать». Без фото — буквы имени, как сейчас.
4. **Логист видит фото** в списке «Водители», «Кто свободен», откликах, сделке, чате и карточке водителя.
   - Видят все вошедшие сотрудники компаний, и непроверенные компании тоже.
   - На публичных страницах (052) и без входа — нет.
   - `GET /drivers/:id/avatar`: только с токеном, `Cache-Control: private, max-age=86400`, обычный лимит запросов.
   - Миниатюра ~200 px: сжать при загрузке, чтобы список водителей не тянул большие файлы.
5. **Админка.** Фото профиля в карточке водителя; «Убрать фото» (жалоба на неподходящее фото) с записью в журнал.
6. ARB, 4 языка.
7. **Тесты:**
   - бэкенд: без токена — 401; с токеном любой компании — 200; после «Убрать» — 404; селфи проверки по-прежнему недоступно вне сделки;
   - e2e: водитель соглашается → логист видит фото в списке водителей.

## Готово, когда
- Водитель с фото виден логисту с лицом во всех списках; без фото — буквы.
- Фото ставится только с согласия водителя и убирается им самим или админом.
- `scripts/e2e.sh` зелёный на iPhone SE и Android 360 dp + Chrome.
