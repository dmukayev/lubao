## Форма груза
1. **Чипы категорий скрыть.** После выбора товара или своего варианта с определённой категорией — под полем одна строка мелко серым: «Категория: Продукты · изменить» (ключ `postCargoCategoryLine`). «Изменить» раскрывает чипы на месте; после выбора они снова сворачиваются.
2. **Чипы показывать только** для своего варианта («Добавить: „…“»), когда категорию определить нельзя, — под заголовком **«Категория»** (а не «Что везёте»). Пустая категория → ошибка у чипов с прокруткой (072).
3. Заголовок над чипами — ключ `postCargoCategory` → «Категория» (4 языка). Подпись поля остаётся «Что везёте?».

## Подсказки
4. **Товары, не коды.** В подсказках показывать только товары из `goods` (и частые товары компании); код в строке подсказки **не показывать**, только «Название · Категория» (+ «Опасный груз»). Коды HS (`hs_codes`) ищутся только при вводе цифр; буквенный ввод по `hs_codes.name` — убрать из подсказок (слишком длинные официальные названия путают). Если по буквам ничего нет в `goods` — только «Добавить: „…“».
5. **Несколько товаров на одно слово** — отдельные позиции справочника с понятными названиями: «Кукуруза (зерно)», «Кукуруза консервированная», «Мука кукурузная». Пройти `goods.json`: где один товар покрывает разные вещи — разбить; у каждого синонимы на 4 языках.
6. **Код у товара необязателен и может быть 4-значным** (позиция). Снять ограничение «ровно 6 цифр» на `goods.hsCode`, валидировать 4 или 6 цифр. Категория из кода — по главе (первые 2), как сейчас.

## Где показывается
7. В карточке груза код ТН ВЭД мелко серым остаётся, если он есть у товара. В ленте, строках и push — только название товара.
