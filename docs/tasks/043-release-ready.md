## Что сделать
1. **Удаление аккаунта:** `DELETE /auth/me` — анонимизация (имя/телефон/email → заглушки, файлы документов и идентификаторы удалить, сделки/отзывы остаются обезличенными), отзыв всех сессий; кнопка «Удалить аккаунт» в профиле водителя и логиста с подтверждением. Владелец компании с сотрудниками — сначала передать владение.
2. **Согласие и документы:** экран согласия на обработку ПДн перед первой загрузкой документа (галочка, текст на 4 языках, запись `consentAt`/версия в БД); ссылки «Условия» и «Политика конфиденциальности» на экране входа и в профиле (веб-страницы `/legal/terms`, `/legal/privacy` на 4 языках — тексты-заготовки, юрист правит). В политике — хранение в РК, DeepSeek для перевода, срок хранения, удаление. **Оферта для компании** (`/legal/offer`): Lubao — информационная площадка, не перевозчик и не экспедитор, не сторона договора перевозки и не отвечает за груз, сроки и оплату; принимается галочкой при регистрации компании (`offerAcceptedAt`, версия). Экран входа: «Продолжая, вы принимаете Условия и Политику» с ссылками; Профиль → «О приложении»: Условия, Политика, Оферта (у логиста), версия, «Удалить аккаунт». Тексты — заготовки, в прод после юриста (пометить в release.md как обязательный шаг).
3. **Предохранитель прода** (`main.ts`): при `NODE_ENV=production` сервер **не стартует**, если `SMS_PROVIDER=console`, нет SMTP, пустой `CORS_ALLOWED_ORIGINS`, дефолтные пароли Postgres/MinIO, короткие `JWT_SECRET/IDENTIFIER_KEY/IDENTIFIER_PEPPER`. Dev-коды 1111 — только `NODE_ENV!=production`.
4. **Безопасность:** `helmet`; `@nestjs/throttler` глобально + лимит по IP на register/forgot/sms; одинаковый ответ при «email уже занят» (025); WebSocket CORS = `CORS_ALLOWED_ORIGINS`; загрузки — проверка magic bytes, расширение по типу, квота на пользователя (50 файлов/сутки); `documentFileSource` → `audit_log`; whitelist ключей `PATCH /admin/settings/:key`; ручная блокировка идентификатора в админке (ИИН/телефон/госномер + причина) и экран чёрного списка.
5. **Админ в проде:** CLI `pnpm admin:create --email --password` (bcrypt) + env `ADMIN_BOOTSTRAP_EMAIL/PASSWORD_HASH` при первом старте, если админов нет.
6. **Прод-инфраструктура:** multi-stage `Dockerfile` (`prisma migrate deploy` → `node dist/main.js`), `docker-compose.prod.yml`: Postgres/Redis/MinIO только во внутренней сети, nginx с TLS (Let's Encrypt), админка за Tailscale (030); `pg_dump` ежедневно + копия бакета в отдельное хранилище, проверка восстановления описана в `infra/README.md`; `/health` проверяет Postgres/Redis/MinIO; Sentry (или аналог) в бэкенде и Flutter; логи без ПДн (маска телефонов/ИИН).
7. **Фирменный знак везде** (утверждён 2026-10-07, `design/brand/README.md`): `flutter_launcher_icons` из `icon-1024.png` (iOS) и adaptive (foreground + фон `#FFF3DC`) для Android, приложение и админка; заставка — `mark` на кремовом фоне + «Lubao» (без `flutter_native_splash` с Google-зависимостями — свои ресурсы); шапка экрана входа водителя и логиста, шапка админки, письма — `logo-horizontal`; веб: favicon/PWA-иконки, `<title>Lubao`, `manifest.json` имя и цвета; `web/index.html` описание вместо «A new Flutter project». Название приложения «Lubao» на всех платформах и языках. Скриншоты иконки на домашнем экране iPhone 16e и Android — в итог.
8. **Выпуск:** `minAppVersion` в `app_settings`, при старте приложения экран «Обновите приложение» с кнопкой (ссылка `https://<APP_HOST>/app` → APK / Google Play / TestFlight); Android — подпись релизным ключом (keystore вне репозитория, инструкция), `applicationId`/`bundleId` = `kz.darkhan.lubao` на обеих платформах (см. `docs/release.md`, **сделать первым пунктом 043, до Firebase-файлов**), название «Lubao», иконка; TestFlight-сборка (инструкция в `docs/release.md`); веб логиста — CanvasKit и шрифты (Onest + Noto Sans SC) с своего сервера (020 часть А) — нужно и для КЗ: без gstatic быстрее и стабильнее.
9. **Сессия водителя — 180 дней бездействия** (сейчас 90, `token.service.ts: REFRESH_TTL_MS.DRIVER`), продление при каждом открытии остаётся; логист 30 дней, админ 12 ч — без изменений. Решение 2026-10-07.
10. Скрипт `prisma/backfill-identifiers.ts` — в чек-лист первого деплоя (`docs/release.md`).
11. **Защита от парсинга** (решение 2026-10-07):
   - телефоны **не отдаются списком**: в ленте грузов, «Кто свободен», откликах — без номеров; номер отдаёт отдельный `POST /cargos/:id/contact` / `POST /drivers/:id/contact` по нажатию «Позвонить»/WhatsApp, пишет `contact_events` (уже есть) и возвращает номер;
   - водитель без проверки видит телефон груза **только после своего отклика** (`PENDING/INVITED→PENDING`) на этот груз; проверенный — по нажатию сразу; логист — по нажатию, только проверенная компания;
   - лимиты: открытий номера ≤ 30/сутки на пользователя, лента ≤ 50 записей на страницу (пагинация), ≤ 60 запросов/мин на пользователя (throttler п.4); превышение → 429 с понятным текстом, 3 превышения за сутки → «на разбор» в админке;
   - админка «Требует внимания»: аккаунт с ≥ 20 открытий номеров за сутки и 0 откликов/сделок — строка с кнопками «Заблокировать»/«Всё в порядке»;
   - устройства: не более 3 активных сессий на аккаунт (старшая отзывается), «Мои устройства» уже есть;
   - тесты: номер не в списках (snapshot DTO), отклик открывает номер, лимит 30 → 429, 4-я сессия отзывает 1-ю; e2e: «Готов взять» → «Позвонить» появляется.
12. Тесты: предохранитель (стартует/не стартует), удаление аккаунта (анонимизация, сессии), throttler; e2e: согласие перед загрузкой, экран force-update по моку `minAppVersion`.
