11. **Защита от парсинга** (решение 2026-10-07):
   - телефоны **не отдаются списком**: в ленте грузов, «Кто свободен», откликах — без номеров; номер отдаёт отдельный `POST /cargos/:id/contact` / `POST /drivers/:id/contact` по нажатию «Позвонить»/WhatsApp, пишет `contact_events` (уже есть) и возвращает номер;
   - водитель без проверки видит телефон груза **только после своего отклика** (`PENDING/INVITED→PENDING`) на этот груз; проверенный — по нажатию сразу; логист — по нажатию, только проверенная компания;
   - лимиты: открытий номера ≤ 30/сутки на пользователя, лента ≤ 50 записей на страницу (пагинация), ≤ 60 запросов/мин на пользователя (throttler п.4); превышение → 429 с понятным текстом, 3 превышения за сутки → «на разбор» в админке;
   - админка «Требует внимания»: аккаунт с ≥ 20 открытий номеров за сутки и 0 откликов/сделок — строка с кнопками «Заблокировать»/«Всё в порядке»;
   - устройства: не более 3 активных сессий на аккаунт (старшая отзывается), «Мои устройства» уже есть;
   - тесты: номер не в списках (snapshot DTO), отклик открывает номер, лимит 30 → 429, 4-я сессия отзывает 1-ю; e2e: «Готов взять» → «Позвонить» появляется.
12. Тесты: предохранитель (стартует/не стартует), удаление аккаунта (анонимизация, сессии), throttler; e2e: согласие перед загрузкой, экран force-update по моку `minAppVersion`.
