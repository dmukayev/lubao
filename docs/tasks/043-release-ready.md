# 043 — «Можно выпускать»: закон, безопасность прода, выпуск

Статус: не начато · после 042. Оценка: 1,5 дня.
Аудит 2026-10-06 (безопасность/эксплуатация). Условие первого чужого пользователя: сервер в облаке РК, не домашний Мак.

## Что сделать
1. **Удаление аккаунта:** `DELETE /auth/me` — анонимизация (имя/телефон/email → заглушки, файлы документов и идентификаторы удалить, сделки/отзывы остаются обезличенными), отзыв всех сессий; кнопка «Удалить аккаунт» в профиле водителя и логиста с подтверждением. Владелец компании с сотрудниками — сначала передать владение.
2. **Согласие и документы:** экран согласия на обработку ПДн перед первой загрузкой документа (галочка, текст на 4 языках, запись `consentAt`/версия в БД); ссылки «Условия» и «Политика конфиденциальности» на экране входа и в профиле (веб-страницы `/legal/terms`, `/legal/privacy` на 4 языках — тексты-заготовки, юрист правит). В политике — хранение в РК, DeepSeek для перевода, срок хранения, удаление.
3. **Предохранитель прода** (`main.ts`): при `NODE_ENV=production` сервер **не стартует**, если `SMS_PROVIDER=console`, нет SMTP, пустой `CORS_ALLOWED_ORIGINS`, дефолтные пароли Postgres/MinIO, короткие `JWT_SECRET/IDENTIFIER_KEY/IDENTIFIER_PEPPER`. Dev-коды 1111 — только `NODE_ENV!=production`.
4. **Безопасность:** `helmet`; `@nestjs/throttler` глобально + лимит по IP на register/forgot/sms; одинаковый ответ при «email уже занят» (025); WebSocket CORS = `CORS_ALLOWED_ORIGINS`; загрузки — проверка magic bytes, расширение по типу, квота на пользователя (50 файлов/сутки); `documentFileSource` → `audit_log`; whitelist ключей `PATCH /admin/settings/:key`; ручная блокировка идентификатора в админке (ИИН/телефон/госномер + причина) и экран чёрного списка.
5. **Админ в проде:** CLI `pnpm admin:create --email --password` (bcrypt) + env `ADMIN_BOOTSTRAP_EMAIL/PASSWORD_HASH` при первом старте, если админов нет.
6. **Прод-инфраструктура:** multi-stage `Dockerfile` (`prisma migrate deploy` → `node dist/main.js`), `docker-compose.prod.yml`: Postgres/Redis/MinIO только во внутренней сети, nginx с TLS (Let's Encrypt), админка за Tailscale (030); `pg_dump` ежедневно + копия бакета в отдельное хранилище, проверка восстановления описана в `infra/README.md`; `/health` проверяет Postgres/Redis/MinIO; Sentry (или аналог) в бэкенде и Flutter; логи без ПДн (маска телефонов/ИИН).
7. **Выпуск:** `minAppVersion` в `app_settings`, при старте приложения экран «Обновите приложение» с кнопкой (ссылка `https://<APP_HOST>/app` → APK / Google Play / TestFlight); Android — подпись релизным ключом (keystore вне репозитория, инструкция), `applicationId`/`bundleId` финальные, название «Lubao», иконка; TestFlight-сборка (инструкция в `docs/release.md`); веб логиста — CanvasKit и шрифты (Onest + Noto Sans SC) с своего сервера (020 часть А) — нужно и для КЗ: без gstatic быстрее и стабильнее.
8. **Сессия водителя — 180 дней бездействия** (сейчас 90, `token.service.ts: REFRESH_TTL_MS.DRIVER`), продление при каждом открытии остаётся; логист 30 дней, админ 12 ч — без изменений. Решение 2026-10-07.
9. Скрипт `prisma/backfill-identifiers.ts` — в чек-лист первого деплоя (`docs/release.md`).
10. Тесты: предохранитель (стартует/не стартует), удаление аккаунта (анонимизация, сессии), throttler; e2e: согласие перед загрузкой, экран force-update по моку `minAppVersion`.
