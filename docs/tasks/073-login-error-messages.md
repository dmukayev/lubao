# 073 — Вход: «Неверный email или пароль», а не «Что-то пошло не так»

Статус: **готово** (2026-10-13).
- Причина «Что-то пошло не так»: перехватчик Dio на 401 от самого входа пытался обновить токен и читал его из защищённого хранилища; в браузере по http-адресу (админка / кабинет по IP) хранилище падает — исключение вылетало из перехватчика и подменяло ошибку. Исправлено: запросы входа (`/auth/company/login`, `/auth/admin/login`, `/auth/phone/*`, регистрация и сброс пароля) не трогаются; токены при недоступном хранилище живут в памяти вкладки.
- п.1: бэкенд — коды вместо текстов: `INVALID_CREDENTIALS` (одинаково для неизвестного email и неверного пароля), `LOCKED_OUT` + `retryAfterSec` (429), `INVALID_CODE`, `CODE_EXPIRED`, `CODE_ATTEMPTS_EXCEEDED`, `RATE_LIMITED`, `PHONE_OTHER_ROLE`, `ACCOUNT_BLOCKED`; русские тексты из кода сервера убраны.
- п.2: перехватчик — см. выше.
- п.3–4: приложение и админка — «Неверный email или пароль» под полем пароля (поле очищается, курсор в нём), «Слишком много попыток. Попробуйте через N мин» с обратным отсчётом (кнопка «Войти» неактивна), «Неверный код» / «Код устарел — отправьте новый» / «Слишком много попыток — отправьте новый код», «Нет связи с сервером» — только без сети; общая функция `authErrorText` (lubao_core), 4 языка.
- п.5: юнит — код → текст и «вход без обновления токена»; бэкенд — коды; e2e `auth_errors` (логист: неверный пароль, водитель: неверный код) и админка `17-login-errors` (Chrome).
- Попутно (найдено e2e): экран выбора роли прокручивается (под клавиатурой на SE с крупным шрифтом переполнялся); профиль водителя меняет сессию только при новых данных; для e2e часовые лимиты кодов настраиваются (`SMS_HOURLY_LIMIT_PER_*`, только вне production) — все входы e2e идут с одного адреса; шаг logist_publish открывает сделку нажатием по плашке статуса (имя водителя открывает его карточку); помощники e2e устойчивее (мастер регистрации, запрос кода).
- Проверка: полный `scripts/e2e.sh` — iPhone SE и админка в Chrome зелёные, на Android 360 всё, кроме двух шагов (нестабильность самих тестов, исправлено) — `evidence/073/e2e-full-run.md`; повтор этих сценариев на Android 360 (`trade_offers`, `auth_errors`) — зелёный, `evidence/073/e2e-android-rerun.md`.
Откуда: владелец 2026-10-13 — при неверном логине или пароле показывается «Что-то пошло не так».
Оценка: 2–3 часа.

## Что известно
- Бэкенд (`auth.service.ts` — `loginCompany`, вход админа) отвечает 401 с текстом `Invalid email or password`, **без кода**. Блокировка после 5 попыток — тоже 401, текст по-русски прямо в коде.
- В `company_login_screen.dart` есть ветка `status == 401 → companyLoginInvalidCredentials`, но владелец видит «Что-то пошло не так». Вероятная причина — перехватчик Dio на 401 пытается обновить токен и подменяет ошибку. Сначала воспроизвести и найти настоящую причину, не гадать.

## Что сделать
1. **Бэкенд — коды вместо текстов** (вход логиста, вход админа, сброс пароля, вход водителя по коду):
   - `INVALID_CREDENTIALS` — неверный email или пароль;
   - `LOCKED_OUT` + `retryAfterSec` — блокировка;
   - `INVALID_CODE`, `CODE_EXPIRED` — для кода из SMS / письма;
   - `ACCOUNT_BLOCKED`.

   Ответ одинаковый для «нет такого email» и «неверный пароль» (не раскрываем, есть ли аккаунт). Русский текст из кода убрать.
2. **Перехватчик Dio:** не обновлять токен и не подменять ошибку на запросах `/auth/login*`, `/auth/admin/login`, `/auth/otp/*`, `/auth/password/*`.
3. **Приложение и админка — тексты (ARB, 4 языка):**
   - «Неверный email или пароль» — **под полем пароля**, красным (как в 072). Поле пароля очищается, курсор в нём;
   - «Слишком много попыток. Попробуйте через 14 мин» — с обратным отсчётом;
   - «Неверный код» / «Код устарел — отправьте новый»;
   - «Нет связи с сервером» — только когда действительно нет сети;
   - «Что-то пошло не так» — только для неизвестных ошибок 5xx.
4. **Админка** (`lubao_admin`, вход): то же.
5. **Тесты:**
   - юнит на соответствие код → текст;
   - e2e: логист вводит неверный пароль → видит «Неверный email или пароль» (на iPhone SE, Android 360 и в Chrome);
   - админ — то же в Chrome;
   - водитель вводит неверный код → «Неверный код».

## Готово, когда
- Ни на одном экране входа при неверных данных нет «Что-то пошло не так».
- Шаги входа в e2e зелёные на iPhone SE и Android 360 (крупный шрифт) + админка в Chrome.
