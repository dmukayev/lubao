# 011 — Уведомления и чат в реальном времени

Статус: не начато · после 006

## Текущее состояние
`NotificationSetting` и enum `NotificationChannel` (PUSH, WECOM, …) есть в схеме, модуля уведомлений и WebSocket нет.

## Что сделать
### Модуль `notifications` (бэкенд)
1. Единая точка: `notify(userId | companyId, event, payload)` → рассылает по включённым каналам. Очередь на Redis (BullMQ), повтор при ошибке.
2. Каналы:
   - **push:** FCM (Android вне Китая), APNs (iOS), JPush (Android в Китае — определять по региону/наличию Google Play Services на устройстве). Таблица токенов устройств, привязка к сессии из 006.
   - **WeCom:** у компании поле `wecomWebhookUrl`; владелец вставляет адрес бота своей группы в профиле компании; кнопка «Проверить» шлёт тестовое сообщение.
   - email и sms — интерфейс есть, реализацию отложить.
3. Тексты уведомлений — на языке получателя (kk/ru/zh), шаблоны в бэкенде.

### События по умолчанию
| Событие | Кому | Каналы |
|---|---|---|
| Новый подходящий груз (матч по стране/кузову/допускам) | водитель | push |
| Логист пригласил к грузу | водитель | push |
| Новое сообщение в чате | получатель | push (не чаще 1 раза в минуту на чат) |
| Водитель откликнулся на груз | логист-автор, компания | push, WeCom |
| Новый водитель на точке под фильтры компании | компания | WeCom (дайджест раз в час) |
| Смена статуса сделки | обе стороны | push, WeCom |
| Документ отклонён / все документы одобрены | водитель | push, deep link на профиль |
| «Договорились?» через 2 часа после звонка | обе стороны | push |

4. Настройки уведомлений в профиле: вкл/выкл по каждой группе событий.
5. Deep links: каждое уведомление открывает нужный экран (груз, сделку, чат, профиль).

### Чат в реальном времени
6. Socket.IO-шлюз с авторизацией по JWT (из 006): комнаты по чатам, события `message:new`, `message:read`, `typing`.
7. Клиент: подключение при открытом приложении, переподключение; если сокет недоступен — запросы раз в 10 секунд (fallback). Проверить работу из Китая.

## Готово, когда
- Водитель получает push о приглашении на Android и iOS; логист в Китае — push через JPush или сообщение в группе WeCom.
- Сообщение в чате появляется у собеседника без обновления экрана.
- Выключенная в настройках группа событий не присылает уведомлений.
